## תרגיל 1: שיפור פרומפטים (עבודה בזוגות - 15 דקות)

### הנחיות:
לכל פרומפט "גרוע", כתבו **גרסה משופרת** עם נוסחת RTCF (Role, Task, Context, Format).

| # | פרומפט גרוע | פרומפט משופר (RTCF) |
|---|---|---|
| 1 | "תכתוב לי פוסט לפייסבוק" | |
| 2 | "תנתח את הנתונים" | |
| 3 | "תכתוב מייל ללקוח" | |
| 4 | "תבנה לי אתר" | |
| 5 | "תן לי רעיונות לעסק" | |

### תשובות לדוגמה:

**פרומפט 1 משופר:**
"אתה מומחה לשיווק ברשתות חברתיות בשוק הישראלי (Role). כתוב פוסט לפייסבוק שמקדם סדנת Prompt Engineering (Task). קהל יעד: בעלי עסקים קטנים בישראל שרוצים ללמוד AI. הסדנה ב-500 ש"ח, ביום חמישי הקרוב, אונליין (Context). אורך: 5-7 שורות, כלול CTA אחד, אימוג'י אחד בהתחלה (Format)."

**פרומפט 2 משופר:**
"אתה אנליסט עסקי עם ניסיון בניתוח מכירות (Role). נתח את טבלת המכירות המצורפת וזהה 3 תובנות עיקריות (Task). הנתונים הם מכירות חודשיות של חנות אונליין ב-12 החודשים האחרונים (Context). הצג בפורמט: תובנה + נתון תומך + המלצה לפעולה (Format)."

## תרגיל 2: זיהוי טכניקות (עבודה אישית - 10 דקות)

### הנחיות:
לכל פרומפט, זהו איזו טכניקה הוא משתמש בה.

| # | הפרומפט | טכניקה |
|---|---|---|
| 1 | "סווג את הביקורת הבאה כחיובית או שלילית: 'השירות היה מעולה'" | |
| 2 | "הנה 3 דוגמאות לסיווג: 'אהבתי'→חיובי, 'נורא'→שלילי, 'בסדר'→ניטרלי. עכשיו סווג: 'לא רע'" | |
| 3 | "חשב את הרווח הנקי. חשוב שלב אחרי שלב." | |
| 4 | "אתה יועץ עסקי מומחה. נתח את ההצעה הבאה." | |
| 5 | "חשוב על 3 אסטרטגיות שונות, נתח כל אחת, ובחר את הטובה." | |
| 6 | "תן 3 תשובות שונות ובחר את הנכונה ביותר." | |

### תשובות:
1. **Zero-Shot** – שאלה ישירה ללא דוגמאות
2. **Few-Shot** – 3 דוגמאות לפני הבקשה
3. **Chain of Thought (CoT)** – "חשוב שלב אחרי שלב"
4. **Role Prompting** – "אתה יועץ עסקי מומחה"
5. **Tree of Thought (ToT)** – 3 נתיבים מקבילים ובחירה
6. **Self-Consistency** – 3 תשובות ובחירת הטובה

## תרגיל 3: בניית System Prompt (עבודה בזוגות - 20 דקות)

### הנחיות:
בחרו אחד מהתרחישים הבאים ובנו **System Prompt מלא** לפי המבנה: Role, Success Criteria, Constraints, Output Format, Uncertainty Handling.

**תרחישים:**
1. בוט שירות לקוחות לחנות בגדים אונליין בישראל
2. עוזר אישי לעורך דין – סיכום מסמכים משפטיים
3. יועץ פיננסי AI לבעלי עסקים קטנים
4. בוט שמנהל הזמנות במסעדה דרך וואטסאפ

### מבנה נדרש:

```
Role: [מי ה-AI? רקע, ניסיון, תחום]

Success Criteria: [מתי התשובה נחשבת טובה?]

Constraints:
- [מה אסור?]
- [מה חובה?]
- [מגבלות]

Output Format: [איך לענות? מבנה, אורך, שפה]

Uncertainty: [מה לעשות כשלא בטוח?]
```

### תשובה לדוגמה (תרחיש 1):

```xml
<system>
<role>
אתה נציג שירות לקוחות של "סטייל פלוס", חנות בגדים אונליין ישראלית.
אתה ידידותי, מקצועי ויעיל. אתה מדבר בעברית בגובה העיניים.
</role>

<success_criteria>
תשובה מוצלחת היא: קצרה (עד 3 משפטים), מועילה, וכוללת פעולה ברורה.
</success_criteria>

<constraints>
- לעולם אל תמציא מידע על מוצרים, מחירים או מדיניות
- אל תציע הנחות שלא אושרו
- אם מדובר בתלונה, הבע אמפתיה לפני שמציע פתרון
- שמור על טון חיובי גם כשהלקוח כועס
</constraints>

<output_format>
ענה בעברית. עד 3 משפטים. אם צריך לבדוק משהו, אמור ללקוח שתחזור אליו.
</output_format>

<uncertainty>
אם אתה לא בטוח במידע, אמור: "אני צריך לבדוק את זה. רגע אחד ואחזור אליך עם תשובה מדויקת."
לעולם אל תנחש.
</uncertainty>
</system>
```

### בדיקה:
אחרי שכתבתם את ה-System Prompt, שלחו אותו ל-Claude/ChatGPT ושאלו 3 שאלות כלקוח. האם התשובות תואמות את ההנחיות?

## תרגיל 5: CoT vs Thinking Mode (עבודה אישית - 10 דקות)

### הנחיות:
שלחו את אותה שאלה מתמטית-עסקית ב-3 דרכים שונות, והשוו תוצאות:

**השאלה:**
"חנות אונליין מוכרת 200 מוצרים בחודש במחיר ממוצע של 150 ש"ח. עלות סחורה 40%, עלות משלוח 18 ש"ח למוצר, עמלת סליקה 2.5%, שיווק 3,000 ש"ח בחודש, שכירות מחסן 2,000 ש"ח. מה הרווח החודשי?"

**דרך א – Zero-Shot:** שלחו את השאלה כמו שהיא.
**דרך ב – CoT:** הוסיפו "חשוב שלב אחרי שלב."
**דרך ג – Thinking Mode:** הפעילו Extended Thinking / Thinking Mode בממשק.

| דרך | תשובה | נכון? | זמן תגובה |
|---|---|---|---|
| Zero-Shot | | | |
| CoT | | | |
| Thinking Mode | | | |

### תשובה נכונה:
- הכנסות: 200 × 150 = 30,000 ש"ח
- עלות סחורה: 30,000 × 40% = 12,000 ש"ח
- משלוח: 200 × 18 = 3,600 ש"ח
- סליקה: 30,000 × 2.5% = 750 ש"ח
- שיווק: 3,000 ש"ח
- שכירות: 2,000 ש"ח
- **סה"כ הוצאות: 21,350 ש"ח**
- **רווח: 8,650 ש"ח (28.8% רווחיות)**
