# תרגילים - שיעור 3.1: מבוא ל-Vibe Coding

## מידע כללי
- **שיעור:** 3.1 - מבוא ל-Vibe Coding
- **סוג השיעור:** עיוני (2 שעות)
- **הערה:** שיעור עיוני – התרגילים ממוקדים בהבנה, ניתוח והתנסות ראשונית

---

## תרגיל 1: הגדרה בשפה שלכם (בכיתה – 5 דקות)

### הנחיות:
כתבו **בשלושה משפטים בלבד** – בלי לצטט את המצגת:
1. מה זה Vibe Coding?
2. מה ההבדל הגדול ביותר בינו לבין תכנות קלאסי?
3. למה לדעתכם הביטוי "שכחו שהקוד קיים" (forget that the code even exists) מסוכן?

### תיאור:
לאחר כתיבה – שתפו עם עמית/ה ותראו אם הגדרתם אותו דבר.

---

## תרגיל 2: בחירת הכלי הנכון (בכיתה – 10 דקות)

### הנחיות:
עבור כל תרחיש, כתבו **איזה כלי תבחרו ולמה** (משפט אחד):

### תרחישים:
1. **שירה**, מעצבת גרפית ללא רקע בתכנות, רוצה לבנות פורטפוליו אינטרנטי בתוך שעה.
2. **דני**, מפתח Backend עם 5 שנות ניסיון ב-Python, רוצה לבנות API לעסק קטן.
3. **מנהלת שיווק** רוצה כלי פנימי שמחבר Google Sheets לדוחות אוטומטיים. אין תקציב פיתוח.
4. **סטארטאפ בן 4 אנשים** צריך MVP לאפליקציה בתוך שבוע. שני מהם מפתחים.
5. **אבא שרוצה לבנות אפליקציה לניהול חוגים לילדים** – אין לו ניסיון טכני.

### הגשה:
שמרו את תשובותיו – נשווה בין תשובות הכיתה ונדון בהבדלים.

---

## תרגיל 3: ניתוח מספרי שוק (בכיתה – 7 דקות)

### הנחיות:
קראו את הנתונים הבאים וענו על השאלות:

**נתונים:**
- Lovable: $0 ל-$400M ARR ב-18 חודשים
- 84% ממפתחים בעולם משתמשים בכלי AI
- 51% מהקוד ב-GitHub נכתב עם עזרת AI
- שוק Vibe Coding: $5B (מרץ 2025) → $12B (2026)

### שאלות:
1. מה המסקנה שלכם לגבי הזדמנויות עסקיות בתחום?
2. אם 51% מהקוד כבר נכתב על ידי AI – מה לדעתכם המיומנות הכי חשובה למפתח ב-2026?
3. Lovable הגיעה ל-$100M ARR ב-8 חודשים. כמה חברות SaaS הצליחו כך בהיסטוריה? (ניחוש מושכל)

---

## תרגיל 4: ניסיון ראשון עם Lovable (שיעורי בית – 30 דקות)

### הנחיות:
1. היכנסו לאתר **lovable.dev**
2. פתחו חשבון חינמי
3. בנו את אחת מהאפליקציות הבאות **ב-3 פרומפטים בלבד**:
   - דף הצגה עצמית (Portfolio page) עם שם, תמונה, כישורים ואמצעי קשר
   - כלי פשוט לניהול רשימת קניות עם אפשרות להוסיף ולמחוק פריטים
   - טופס יצירת קשר לעסק (שם, טלפון, הודעה, כפתור שליחה)

### מה לתעד:
- צילום מסך של הפרומפט הראשון שכתבתם
- צילום מסך של התוצאה הסופית
- **3 דברים שהפתיעו אתכם** (חיובי או שלילי)
- **משהו שרצלתם לשנות אך לא הצלחתם**

### הגשה:
שתפו בקבוצת הוואטסאפ של הקורס לפני השיעור הבא.

---

## תרגיל 5: השוואת כלים בשדה (שיעורי בית – 20 דקות)

### הנחיות:
בצעו **אותה משימה** בשני כלים שונים ותשוו:

**המשימה:**
"תבנה לי דף HTML פשוט עם כותרת, שלוש כפתורים צבעוניים, ותיאור קצר"

**בכלים:**
1. ChatGPT (free) – פשוט כתבו את הבקשה ב-chat
2. Lovable.dev

### מה להשוות:
| קריטריון | ChatGPT | Lovable |
|----------|---------|---------|
| זמן לתוצאה ראשונה | | |
| איכות ויזואלית | | |
| כמה קל לשנות | | |
| האם הייתי מראה ללקוח? | | |

### שאלת חשיבה:
מתי ChatGPT עדיף על Lovable? מתי Lovable עדיף?

## תרגיל 6: מחקר – הכלי שהכי מעניין אתכם (שיעורי בית – 15 דקות)

### הנחיות:
בחרו **כלי אחד** מהרשימה שהכי עניין אתכם בשיעור: Claude Code / Ampcode / Gemini CLI / Codex CLI / Bolt.new / Replit Agent.

חפשו אותו באינטרנט (חפשו את שם הכלי + "review 2026") ומצאו:

### שאלות לחקור:
1. מה המחיר המדויק היום?
2. מה היכולת הכי ייחודית שלו שלא ציינו בשיעור?
3. מה הביקורת הכי נפוצה עליו ב-Reddit / Twitter?
4. איזה משתמש ספציפי (סוג עסק / מקצוע) הכי מרוויח ממנו?

### הגשה:
פסקה אחת של 4-6 משפטים שמסכמת את הממצאים שלכם.

---

## תרגיל 7: משימת בית – תוכנית פעולה אישית

### הנחיות:
כתבו **תוכנית פעולה אישית** בגוף ראשון:

1. **פרויקט שרוצה לבנות:** תארו בקצרה פרויקט אחד שהייתם רוצים לבנות עם Vibe Coding.
2. **הכלי שתבחרו:** איזה כלי תשתמשו בו ולמה?
3. **המחסום הכי גדול שלכם:** מה לדעתכם יהיה הדבר הכי קשה? (טכני? זמן? ידע?)
4. **מה תלמדו בשלב הבא:** מה חסר לכם כדי להתחיל?

### פורמט:
4-8 משפטים, בשפה ישירה ואישית.

**הגישו עד השיעור הבא.**
