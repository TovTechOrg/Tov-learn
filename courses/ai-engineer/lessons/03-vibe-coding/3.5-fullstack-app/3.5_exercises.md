# תרגילים - שיעור 3.5: בניית אפליקציית Full-Stack

## מידע כללי
- **שיעור:** 3.5 - בניית אפליקציית Full-Stack (Frontend + Backend + DB)
- **סוג השיעור:** מעשי (4 שעות)
- **הערה:** כל התרגילים מתבצעים באמצעות Claude Code בטרמינל. יש לפתוח תיקייה ריקה ב-VSCode, לפתוח טרמינל ולהקליד `claude` כדי להתחיל את הסשן.

## תרגיל 1: הגדרת פרויקט ו-CLAUDE.md (בכיתה - 15 דקות)
### הנחיות:
בשלב הראשון, נקים את השלד של הפרויקט שלנו: מערכת הזמנות ל"פלאפל הכרמל" - עסק מקומי שרוצה להשתדרג טכנולוגית. ניצור את הפרויקט ונגדיר ל-Claude את חוקי העבודה שלנו (System Prompt) ברמת הפרויקט.

1. פתחו טרמינל בתיקייה ריקה והפעילו את Claude Code.
2. בקשו מ-Claude לייצר פרויקט Next.js חדש ולהגדיר את קובץ ההנחיות.

**פקודה ל-Claude Code:**
```text
Run `npx create-next-app@latest falafel-carmel --typescript --tailwind --eslint --app --use-npm --src-dir` to create a new project. 
Then, cd into the directory and create a `CLAUDE.md` file. 
In the CLAUDE.md, write strict guidelines for this project: 
1. Use Next.js App Router. 
2. Default to Server Components, use Client Components only when interactivity is needed (e.g., hooks, events). 
3. Use Server Actions for all data mutations. 
4. UI styling must use Tailwind CSS.
5. Tech stack includes Prisma and PostgreSQL.
```

### שאלות:
1. פתחו את הקובץ `CLAUDE.md` שנוצר. מדוע חשוב להגדיר בו את ההעדפה ל-Server Components כברירת מחדל?
2. איך קובץ ה-CLAUDE.md משפיע על סשנים עתידיים שלנו מול הטרמינל?

## תרגיל 2: הגדרת מסד הנתונים - Prisma Schema (בכיתה - 30 דקות)
### הנחיות:
כעת נבנה את מודל הנתונים. נדרשים לנו שני מודלים מרכזיים: פריט בתפריט (`MenuItem`) והזמנה (`Order`).

1. ודאו שיש לכם מחרוזת התחברות (Connection String) ל-PostgreSQL (למשל מ-Supabase, Neon, או לוקאלי).
2. הנחו את Claude להתקין את Prisma, לאתחל אותו, ולבנות את הסכימה עבור פלאפל הכרמל.

**פקודה ל-Claude Code:**
```text
Install prisma and @prisma/client. Run `npx prisma init`.
Update the schema.prisma file to include two models for an Israeli restaurant:
1. MenuItem: id (uuid), name (string, e.g., 'מנת פלאפל', 'סביח'), description (string), price (float), isSpicy (boolean), createdAt.
2. Order: id (uuid), customerName (string), totalAmount (float), status (enum: PENDING, PREPARING, READY, DELIVERED), createdAt.
Also, add a relation where an Order can have multiple MenuItems (create an OrderItem join table).
Once done, ask me for my DATABASE_URL, add it to .env, and run the prisma migration called 'init_falafel_db'.
```

### שאלות:
1. אילו קבצים Claude Code היה צריך ליצור/לשנות כדי להשלים משימה זו?
2. מדוע השתמשנו בטבלת גישור (`OrderItem`) במקום לקשר ישירות בין הזמנה לפריט?

## תרגיל 3: Server Actions לפעולות CRUD (בכיתה - 40 דקות)
### הנחיות:
כדי שהאפליקציה תוכל לתקשר עם מסד הנתונים בצורה מאובטחת, נשתמש ב-Server Actions. פעולות אלו ירוצו על השרת (Backend) בלבד.

1. צרו קובץ לקליינט של פריזמה.
2. צרו קובץ פעולות לניהול התפריט.

**פקודה ל-Claude Code:**
```text
1. Create a `src/lib/prisma.ts` file to instantiate the Prisma client (following Next.js best practices for global instances).
2. Create `src/actions/menuActions.ts`. Write the following Server Actions using the prisma client:
- getMenuItems(): Fetch all menu items ordered by creation date.
- createMenuItem(formData: FormData): Extract name, description, price, and isSpicy, and save to DB. Call revalidatePath('/') at the end.
- deleteMenuItem(id: string): Delete an item and revalidate.
Ensure all functions have explicit TypeScript return types and error handling.
```

### שאלות:
1. מה תפקיד הפונקציה `revalidatePath` בסוף פעולת היצירה?
2. מדוע אנו מעבירים `FormData` לפעולת ה-Create במקום אובייקט JSON רגיל?

## תרגיל 6: Vibe Coding - עריכת מספר קבצים במקביל (בכיתה - 35 דקות)
### הנחיות:
זה הזמן להרגיש את העוצמה של Claude Code בפרויקט Full-Stack. נבקש ממנו להוסיף פיצ'ר שדורש נגיעה ב-Frontend, Backend ובתלויות צד שלישי: הוספת Toast Notifications (התראות קופצות).

**פקודה ל-Claude Code:**
```text
I want to add toast notifications to the app. 
1. Install the `sonner` package.
2. Add the <Toaster /> component to the root layout.
3. Refactor `AddMenuItemForm.tsx` to not use the native 'action' attribute directly. Instead, intercept the form submission using an onSubmit handler, call the Server Action programmatically, and display a success toast ("המנה התווספה בהצלחה!") or an error toast if it fails.
4. Update `createMenuItem` action to return an object like { success: boolean, message: string } instead of just throwing errors.
Review all affected files and ensure the flow works seamlessly.
```

*בזמן ש-Claude עובד, ננהל דיון בכיתה:* מתי הייתם משתמשים ב-Claude Code כפי שעשינו עכשיו, ומתי הייתם פותחים פרויקט כזה ב-Lovable או Bolt.new? (התשובה תתמקד בשליטה בקוד המקור וגישה למסדי נתונים מורכבים מול מהירות הקמה של UI בלבד).

### שאלות:
