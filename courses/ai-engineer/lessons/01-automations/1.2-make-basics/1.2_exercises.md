## תרגיל 2: Scenario ראשון – שורה ב-Sheets שולחת מייל (זוגות, 25 דקות)

### הנחיות:
בנו Scenario שמחכה לשורה חדשה ב-Google Sheets ושולח מייל.

### שלבים:

**שלב 1 — הכינו Google Sheets:**
- צרו Spreadsheet חדש בשם "לקוחות לפולו-אפ"
- הוסיפו עמודות: שם, אימייל, נושא הפנייה, תאריך

**שלב 2 — בנו את ה-Scenario:**

| Module | אפליקציה | Action | הגדרות |
|--------|---------|--------|--------|
| 1 (Trigger) | Google Sheets | Watch New Rows | Spreadsheet: לקוחות לפולו-אפ, Max: 1 |
| 2 | Gmail | Send an Email | To: {{אימייל}}, Subject: "תודה שפנית!" |

**שלב 3 — Data Mapping:**
- שדה To: מפו לעמודת אימייל מ-Google Sheets
- שדה Subject: "שלום {{שם}}, קיבלנו את פנייתך לגבי: {{נושא הפנייה}}"
- שדה Content: כתבו תוכן מייל עם שם הלקוח

**שלב 4 — בדיקה:**
- הוסיפו שורה ידנית ל-Google Sheets
- לחצו Run Once
- ודאו שמייל נשלח

### שאלות להגשה:
1. מה קרה כשלחצתם Run Once? כמה Bundles הופיעו?
2. מה הייתה בעיה אחת שנתקלתם בה? איך פתרתם?
3. צלמו screenshot של ה-Scenario המוכן עם המספרים הירוקים אחרי הרצה

## תרגיל 3: Data Mapping מתקדם (אישי, 20 דקות)

### הנחיות:
בהמשך לתרגיל 2, שפרו את תוכן המייל עם פונקציות.

### שינויים לבצע:

**א. עם פונקציה formatDate:**
בשדה Content הוסיפו:
```
תאריך הפנייה: {{formatDate(1. תאריך; "DD/MM/YYYY")}}
```

**ב. עם טקסט דינמי:**
שנו את Subject ל:
```
פנייה חדשה מ-{{upper(1. שם)}} - {{1. נושא הפנייה}}
```

**ג. עם תנאי if:**
הוסיפו לתוכן המייל:
```
{{if(1. נושא הפנייה = "דחוף"; "נטפל מיד!"; "נחזור אליך תוך 24 שעות.")}}
```

### שאלות:
1. מה עשתה הפונקציה `upper`?
2. מה עשה `if`? מתי "נטפל מיד" ומתי "נחזור תוך 24 שעות"?
3. מצאו עוד 2 פונקציות שימושיות ב-Make. תארו מה כל אחת עושה.

## תרגיל 4: הוספת פילטר (זוגות, 15 דקות)

### הנחיות:

### פילטר לבנות:
מלאו שורה ב-Google Sheets עם אימייל שגוי (ללא @) ובדקו שהמייל **לא** נשלח.

**הפילטר:**

- תנאי: מכיל

### ייתר על כן — פילטר כפול (AND):
- **תנאי 1:** אימייל מכיל @
- **תנאי 2:** שם לא ריק

### בדיקה:

|------------|----------------|
| שם: דנה, אימייל: dana@test.com | כן |

| שם: מיכאל, אימייל: bademail | לא |

### שאלות:

## תרגיל 6: Webhook מלא (קבוצות, 30 דקות)

### הנחיות:
בנו את התרחיש המלא שנדגם בשיעור, אבל עם שדה נוסף ותנאי.

### התרחיש:
טופס יצירת קשר מאתר → שמירה ב-Google Sheets → מייל ללקוח → התראה למנהל (אימייל שני)

### מבנה Scenario:

| Module | אפליקציה | פעולה |
|--------|---------|-------|
| 1 | Webhooks | Custom Webhook (Trigger) |
| 2 | Google Sheets | Add a Row |
| 3 | Gmail | Send an Email (ללקוח) |
| 4 | Gmail | Send an Email (למנהל) |

### הגדרות:

**Module 2 — Google Sheets:**
- עמודות: שם, אימייל, טלפון, הודעה, תאריך (now())

**Module 3 — מייל ללקוח:**
- נושא: "קיבלנו את פנייתך!"
- תוכן: "שלום {{שם}}, תודה שפנית. ניצור איתך קשר תוך 24 שעות."

**Module 4 — מייל למנהל:**
- נושא: "ליד חדש: {{שם}}"
- תוכן: כל הפרטים של הלקוח (שם, אימייל, טלפון, הודעה)

**פילטר בין Module 3 ל-4:**
- אימייל מכיל @

### בדיקה עם Postman / curl:
```json
{
  "שם": "שרה כהן",

  "טלפון": "0521234567",
  "הודעה": "מעוניינת בהצעת מחיר לאוטומציה"
}
```

### הגשה:

## תרגיל 7: ניהול שגיאות (אישי, 15 דקות)

### הנחיות:
הוסיפו Error Handling ל-Scenario מתרגיל 6.

### מה לבנות:
אם Module 3 (מייל ללקוח) נכשל — במקום לעצור, שלחו הודעת Gmail למנהל עם הודעת השגיאה.

### שלבים:
1. לחצו ימין על Module 3 (Gmail ללקוח)
2. בחרו "Add error handler"
3. בחרו "Ignore" (המשיך גם כשנכשל)
4. הוסיפו Module חדש בענף השגיאה: Gmail → Send an Email למנהל
5. נושא: "שגיאה! לא הצלחנו לשלוח מייל ל-{{שם}}"
6. תוכן: "שגיאה: {{error.message}}"

### שאלות:
1. מה ההבדל בין "Ignore" ל-"Break" ב-Error Handling?
2. מתי כדאי להשתמש ב-"Retry"?
3. מה יקרה לשורה ב-Google Sheets אם יש שגיאה ב-Gmail?
