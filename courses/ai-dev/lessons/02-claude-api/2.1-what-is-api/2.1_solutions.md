## תרגיל 1: חקירת API ציבורי עם הדפדפן

### תשובות לשאלות:

**Request Method:** `GET` — אנו רק מבקשים לקרוא נתונים, ולכן משתמשים ב-GET.

**Status Code:** `200 OK` — הבקשה הצליחה. משמעות הקוד: השרת מצא את הנתונים שביקשנו והחזיר אותם בהצלחה.

**Content-Type של התשובה:** `application/json;charset=utf-8` — זה אומר שהנתונים שחזרו מובנים כ-JSON (JavaScript Object Notation), כלומר מפתח-ערך מוגדרים בצורה שאנו יכולים לנתח בקוד. ה-`charset=utf-8` מציין את קידוד התווים — UTF-8 תומך בעברית ובשפות נוספות.

## תרגיל 2: שליחת בקשת API עם Postman

### תשובה לשאלה:

לאחר הוספת הפרמטר `q=משרד החינוך`, התשובה שינתה את ה-`records` שבגוף ה-JSON — כעת מוחזרים רק רשומות שמכילות את הביטוי "משרד החינוך". הפרמטר `q` פועל כמסנן חיפוש בצד השרת; במקום להחזיר את כל 5 הרשומות הראשונות, המערכת מחזירה רק תוצאות מתאימות. שימו לב שה-`total` בתגובה גם השתנה בהתאם.

## תרגיל 3: אימות באמצעות API Key

### תשובה לשאלה:

כאשר שולחים בקשה **ללא** `appid`:
- **Status Code:** `401`
- **הודעת שגיאה בגוף:**
```json
{
    "cod": 401,
    "message": "Invalid API key. Please see https://openweathermap.org/faq#error401 for more info."
}
```

**משמעות:** השרת דחה את הבקשה — בין אם לא שלחנו מפתח כלל ובין אם שלחנו מפתח לא פעיל, OpenWeatherMap מחזיר `401` בשני המקרים. ה-API Key הוא "תעודת הזהות" שלנו — בלעדיה, השרת אינו מאפשר גישה.

**הערה:** מפתח API חדש ב-OpenWeatherMap לוקח עד 2 שעות להיות פעיל לאחר ההרשמה.

## תרגיל 4: קריאה ראשונה ל-API של מודל שפה (AI)

### הערות מעשיות — Gemini במקום OpenAI:

אם אין מפתח OpenAI, ניתן להשתמש ב-**Gemini API** של Google. ההבדלים המרכזיים:

| | OpenAI | Gemini |
|--|--------|--------|
| Endpoint | `api.openai.com/v1/chat/completions` | `generativelanguage.googleapis.com/v1beta/models/MODEL:generateContent` |
| אימות | `Authorization: Bearer TOKEN` (Header) | `?key=API_KEY` (Query Param) |
| מבנה Body | `messages: [{role, content}]` | `contents: [{parts: [{text}]}]` |

**Body לבקשת Gemini:**
```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "כתוב לי 3 כותרות קצרות למייל שיווקי עבור חברת הייטק ישראלית המשיקה מוצר חדש בתחום אבטחת הסייבר בענן."
        }
      ]
    }
  ]
}
```

**לגלות אילו מודלים זמינים:** שלחו `GET` ל-`https://generativelanguage.googleapis.com/v1beta/models?key=YOUR_KEY`

**שגיאות נפוצות:**
- `404 NOT_FOUND` — שם המודל לא קיים, בדקו ברשימת המודלים
- `429 limit: 0` — המפתח לא מ-AI Studio. צרו מפתח חדש ב-[aistudio.google.com](https://aistudio.google.com)
- `400 contents is not specified` — ה-Body ריק, בדקו שבחרתם raw → JSON

**תשובה לדוגמה (מבנה תשובת Gemini):**
```json
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "1. \"מגן הענן הישראלי: הגנה חכמה, שקט אמיתי\"\n2. \"עתיד האבטחה נולד היום — בישראל\"\n3. \"סייבר בענן: הצעד הבא להגנה עסקית\""
          }
        ],
        "role": "model"
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 42,
    "candidatesTokenCount": 58,
    "totalTokenCount": 100
  }
}
```

**נקודות חשובות:**
- תוכן התשובה נמצא ב-`candidates[0].content.parts[0].text` (Gemini) לעומת `choices[0].message.content` (OpenAI)
- שדה `usageMetadata` מציג כמה Tokens השתמשנו
- `finishReason: "STOP"` — המודל סיים בצורה תקינה

## תרגיל 5: אוטומציה עם Python וספריית requests

### קוד עם שאלה שונה:

```python
import requests
import json

api_url = "https://api.openai.com/v1/chat/completions"
api_key = "YOUR_OPENAI_API_KEY"

headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

payload = {
  "model": "gpt-3.5-turbo",
  "messages": [
    {
      "role": "system",
      "content": "אתה עוזר וירטואלי שמנוסח באופן מקצועי ועסקי."
    },
    {
      "role": "user",
      "content": "מהם 3 היתרונות המרכזיים של שימוש ב-API בעולם העסקי?"
    }
  ]
}

response = requests.post(api_url, headers=headers, data=json.dumps(payload))

if response.status_code == 200:
    response_data = response.json()
    print(response_data['choices'][0]['message']['content'])
else:
    print(f"Error: {response.status_code}")
    print(response.text)
```

### תשובה לדוגמה שהמודל מחזיר (Gemini) — לשאלה "מהם 3 היתרונות המרכזיים של שימוש ב-API בעולם העסקי?":

```
1. הגברת היעילות והאוטומציה — API מאפשר למערכות שונות לתקשר זו עם זו באופן חלק ואוטומטי...
2. חדשנות ופיתוח מוצרים/שירותים חדשים — API מאפשר גישה לנתונים ופונקציונליות...
3. שיפור חווית הלקוח והגברת התחרותיות — API מאפשר יצירת חוויות לקוח עשירות...
```

**שימו לב:** Gemini מחזיר תשובות מפורטות מאוד עם תתי-סעיפים. בקוד אמיתי ניתן לשלוט על כך דרך ה-prompt — למשל: "ענה בקצרה, רק 3 משפטים, ללא הסברים נוספים".

## תרגיל 6: הבנת תהליך OAuth 2.0

### ניתוח הפרמטרים ב-URL:

| פרמטר | תפקידו |
|-------|---------|
| `appId` (מקביל ל-`client_id`) | מזהה ייחודי של האפליקציה המבקשת גישה. כך שרת Wix יודע *מי* מבקש הרשאות |
| `redirectUrl` (מקביל ל-`redirect_uri`) | לאחר שהמשתמש אישר גישה, Wix ידע לאן להפנות אותו בחזרה עם קוד האישור |

### הסבר תהליך ה-Authorization Code Flow:

```
[משתמש] → [אפליקציה] → [שרת Wix - דף אימות]
                              ↓
                    [משתמש מאשר גישה]
                              ↓
              [Wix מפנה ל-redirectUrl?code=XYZ]
                              ↓
         [שרת האפליקציה מחליף code ב-access_token]
                              ↓
              [שימוש ב-access_token לקריאות API]
```

**מדוע לא מעבירים את ה-access_token ישירות?**
כי ה-`code` הוא חד-פעמי ותקף לזמן קצר. החלפת ה-code ב-token נעשית בצד השרת (server-to-server) בצורה מאובטחת — לא דרך הדפדפן שחשוף לעיני המשתמש.

## תרגיל 7: משימת בית — פתרון לדוגמה

```python
import requests
import json

api_url = "https://api.openai.com/v1/chat/completions"
api_key = "YOUR_OPENAI_API_KEY"

def generate_marketing_description(product_info: str) -> str:
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }

    prompt = (
        f"אתה קופירייטר מקצועי. כתוב תיאור שיווקי של בדיוק 100 מילים עבור המוצר הבא.\n"
        f"המוצר: {product_info}\n\n"
        f"הנחיות: הדגש שלושה יתרונות מרכזיים ללקוח, השתמש בשפה ברורה ומושכת, "
        f"וסיים בקריאה לפעולה (Call-to-Action) ברורה."
    )

    payload = {
        "model": "gpt-3.5-turbo",
        "messages": [
            {
                "role": "system",
                "content": "אתה קופירייטר מקצועי המתמחה בשיווק דיגיטלי."
            },
            {
                "role": "user",
                "content": prompt
            }
        ]
    }

    response = requests.post(api_url, headers=headers, data=json.dumps(payload))

    if response.status_code == 200:
        return response.json()['choices'][0]['message']['content']
    else:
        return f"שגיאה: {response.status_code} - {response.text}"


if __name__ == "__main__":
    my_product = (
        "אפליקציית מובייל ישראלית חדשה לניהול תקציב אישי. "
        "האפליקציה מתממשקת אוטומטית לחשבונות בנק וכרטיסי אשראי, "
        "מזהה הוצאות חריגות באמצעות AI, ומציעה טיפים לחיסכון."
    )

    description = generate_marketing_description(my_product)
    print(description)
```

### תשובה לדוגמה שהמודל מייצר (Gemini):

```
השתלטו על הכסף שלכם עם האפליקציה הישראלית החדשה לניהול תקציב חכם.
ראשית, תיהנו מסנכרון אוטומטי ומלא מול כל חשבונות הבנק וכרטיסי האשראי שלכם.
שנית, הבינה המלאכותית שלנו תזהה עבורכם הוצאות חריגות בזמן אמת ותמנע הפתעות מיותרות.
שלישית, תקבלו טיפים מותאמים אישית לחיסכון שיעזרו לכם להגדיל את החיסכון החודשי בקלות.
הצטרפו לאלפי ישראלים שכבר לקחו אחריות על העתיד הפיננסי שלהם.
הורידו את האפליקציה עוד היום והתחילו לחסוך בחוכמה ובקלות מרבית!
```
