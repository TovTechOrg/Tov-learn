## תרגיל 2: חוויה בזמן אמת - Streaming (מעשי - 25 דקות)
### הנחיות:
נבנה צ'אטבוט בסיסי שמדפיס את התשובה למסך מילה במילה (או ליתר דיוק, טוקן אחר טוקן), מה שיוצר חווית משתמש טובה ומהירה יותר. העיקרון זהה אצל כל הספקים — רק שם המתודה משתנה.

**תרחיש:** עוזר וירטואלי שמסכם כתבות חדשותיות ארוכות בזמן אמת.

### משימות:
1.  כתבו פונקציה המקבלת קלט מהמשתמש בלולאה אינסופית (עד שהמשתמש יקליד "יציאה").
2.  בתוך הלולאה, שלחו את קלט המשתמש למודל Gemini באמצעות `client.models.generate_content_stream(...)` (הגרסה המזרימה ב-SDK החדש).

## תרגיל 3: הרחבת יכולות - Tool Use / Function Calling (מעשי - 40 דקות)
### הנחיות:

**תרחיש:** אתם בונים עוזר AI לאתר קניות ישראלי. העוזר צריך להיות מסוגל לחשב מחיר סופי של מוצר כולל מע"מ (17%).

### משימות:
1.  כתבו פונקציית פייתון פשוטה בשם `calculate_final_price` שמקבלת מחיר בסיס (`base_price`) ומחזירה את המחיר כולל 17% מע"מ.
2.  הגדירו את ה-"כלי" (Tool) עבור ה-API של Gemini באמצעות `types.FunctionDeclaration`, כך שיכיל את שם הפונקציה, תיאור שלה, והפרמטרים שהיא מקבלת.
3.  כתבו קוד ששולח פרומפט למודל, למשל: "אני רוצה לקנות מוצר שעולה 350 ש"ח. מה יהיה המחיר הסופי שלו כולל מע"מ?".
4.  הקוד צריך לטפל בתגובת המודל:
    *   לבדוק אם המודל ביקש להשתמש בכלי שלכם (האם יש `function_call` באחד ה-parts).
    *   אם כן, לחלץ את שם הפונקציה והארגומנטים מהתגובה.
    *   לקרוא לפונקציית הפייתון `calculate_final_price` עם הארגומנטים שהתקבלו.
    *   לשלוח את תוצאת הפונקציה בחזרה למודל בקריאה נוספת, כדי שהוא יוכל לנסח תשובה סופית למשתמש.
5.  הדפיסו את התשובה הסופית והמנוסחת של המודל.

### קוד התחלתי (Starter Code):

```python
import os
from google import genai
from google.genai import types
from dotenv import load_dotenv

load_dotenv()
client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))

# 1. Define the Python function
def calculate_final_price(base_price: float) -> float:
    """Calculates the final price of an item including 17% VAT."""
    vat_rate = 0.17
    final_price = base_price * (1 + vat_rate)
    print(f"[Tool Executed] Calculating VAT for {base_price}. Result: {final_price}")
    return final_price

# 2. Define the tool for the API
price_tool = types.FunctionDeclaration(
    name="calculate_final_price",
    description="חישוב המחיר הסופי של פריט לאחר הוספת מעמ בשיעור 17%. יש להשתמש בכלי זה עבור כל שאלה שקשורה למחיר סופי, מעמ, או עלות כוללת.",
    parameters_json_schema={
        "type": "object",
        "properties": {
            "base_price": {
                "type": "number",
                "description": "המחיר המקורי של הפריט, לפני מעמ. לדוגמה: 500."
            }
        },
        "required": ["base_price"]
    },
)

config = types.GenerateContentConfig(
    tools=[types.Tool(function_declarations=[price_tool])]
)

# 3. Send the initial request
user_prompt = "אני רוצה לקנות אוזניות שעולות 350 שקלים. כמה זה יצא לי סך הכל?"

chat = client.chats.create(model="gemini-3.5-flash-lite", config=config)
response = chat.send_message(user_prompt)

print(f"Initial model response: {response.candidates[0].content.parts}")

# Your code here:
# 4. Check if the model wants to use a tool:
#    fn_calls = [p.function_call for p in response.candidates[0].content.parts if p.function_call]
# 5. If so, extract the function name (fc.name) and arguments (dict(fc.args)).
# 6. Call the actual Python function with the extracted arguments.
# 7. Send the result back to the model to get a natural language response:
#    response = chat.send_message(
#        types.Part.from_function_response(name=fc.name, response={"result": result}))
# 8. Print the final answer (response.text).
```

> **למה `chats.create` ולא `generate_content`?** כי אחרי שהרצנו את הכלי אנחנו צריכים לשלוח את התוצאה **בהמשך אותה שיחה** — המודל חייב לזכור מה הוא ביקש. אובייקט ה-chat שומר את ההיסטוריה בשבילנו. אפשר גם לעשות את זה ידנית עם `generate_content` ורשימת `contents` שגדלה, וזה בדיוק מה שנעשה בתרגיל הבא.

## תרגיל 5: עיצוב אישיות - System Prompt Engineering (מעשי - 20 דקות)
### הנחיות:
נראה כיצד הודעת `system` פשוטה יכולה לשנות באופן דרמטי את אישיות, טון וסגנון התגובה של המודל, גם אם שאלת המשתמש זהה.

**תרחיש:** בוט שירות לקוחות של חברת "פלאפון".

### משימות:
1.  הגדירו שני `system_prompts` שונים:
