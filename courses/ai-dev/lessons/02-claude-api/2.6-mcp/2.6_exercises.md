### הנחיות:
ענו בקצרה ובעזרת דוגמאות על השאלות הבאות. ניתן לדון בזוגות לפני שעונים.

### שאלות:
1.  **הגדרת מושגים:** הסבירו במילים שלכם מה תפקידו של כל אחד מהרכיבים בארכיטקטורת MCP:
    *   **Host:**
    *   **Client:**
    *   **Server:**
2.  **תוכן ב-MCP:** מה ההבדל המהותי בין `Tool` ל-`Resource` ב-MCP? תנו דוגמה לכל אחד מהם בהקשר של חברת פינטק ישראלית.
3.  **MCP מול API:** תארו תרחיש עסקי בחברת Monday.com שבו שימוש ב-MCP יהיה עדיף על חשיפת API מסורתי למודל השפה. הסבירו מדוע. (רמז: חשבו על הרשאות, מורכבות, ואיך המודל "רואה" את הכלים).
4.  **שרטוט ארכיטקטורה:** שרטטו דיאגרמה פשוטה המתארת כיצד Claude Desktop (ה-**Host** - האפליקציה שמריצה בתוכה את ה-Client) יוצר **Client** שמתחבר בחיבור ייעודי לשרת ה-**MCP Server** שבניתם, המספק גישה לכלי הבודק את שערי המניות העדכניים בבורסה בתל אביב.
    - **שימו לב:** ה-Host הוא תמיד אפליקציית ה-AI (למשל Claude Desktop), שמריצה בתוכה Client אחד לכל שרת שהיא מתחברת אליו. השרת עצמו הוא ה-Server בלבד - הוא אף פעם לא "Host".

## תרגיל 2: התקנת שרת MCP קיים - Filesystem (יחיד/זוגות - 25 דקות)
בואו נתנסה בהפעלת שרת MCP קיים ואמיתי, ונחבר אותו ל-**Claude Code (ה-CLI)** בתור Client. זה יעזור לנו להבין איך Client "מגלה" ומתקשר עם הכלים (Tools) שהשרת חושף - וגם ללמוד מקרה מעניין: מתי שרת MCP שעובד עם קבצים בכלל **לא** חושף Resources.

### הנחיות:
1.  ודאו שמותקן לכם Claude Code CLI:
    ```bash
    claude --version
    ```
2.  צרו תיקייה חדשה במחשב בשם `my_mcp_filesystem` ועברו אליה בטרמינל:
    ```bash
    mkdir my_mcp_filesystem
    cd my_mcp_filesystem
    ```
3.  בתוך התיקייה, צרו שתי תתי-תיקיות: `tools` ו-`resources`.
    ```bash
    mkdir tools resources
    ```
4.  בתוך `resources`, צרו קובץ טקסט בשם `miluim_policy.md` והדביקו בו את הטקסט הבא:
    ```markdown
    # נוהל שירות מילואים פעיל - חברת "ישראטק"

    חברת "ישראטק" מכירה בחשיבות שירות המילואים ותומכת בעובדיה המשרתים.
    - עובד היוצא למילואים יקבל את מלוא שכרו מהחברה.
    - החברה תסייע בהשלמת פערים מקצועיים עם חזרתו של העובד.
    - ימי המילואים אינם נספרים כימי חופשה.
    ```
5.  חברו את שרת ה-Filesystem הרשמי ל-Claude Code, מוגבל לתיקייה הנוכחית בלבד:
    ```bash
    claude mcp add filesystem-exercise -- npx -y @modelcontextprotocol/server-filesystem .
    ```
    מה קורה כאן בפועל:
    - `claude mcp add filesystem-exercise` רושם שרת MCP חדש בשם `filesystem-exercise`.
    - כל מה שאחרי ה-`--` היא הפקודה שמריצה בפועל את השרת. `npx -y ...` מוריד ומריץ את חבילת ה-Node.js `@modelcontextprotocol/server-filesystem` (זו **לא** חבילת pip, ואין צורך בהתקנה נפרדת מראש).
    - ה-`.` בסוף אומר לשרת "מותר לך לגשת רק לתיקייה הנוכחית ותתי-התיקיות שלה" - הגנה חשובה, כדי ש-Claude לא יקבל גישה לכל הדיסק.
6.  ודאו שהחיבור הצליח:
    ```bash
    claude mcp list
    claude mcp get filesystem-exercise
    ```
    הסטטוס אמור להופיע כ-`✔ Connected`.
7.  פתחו session חדש של Claude Code בתוך התיקייה (הפקודה `claude`), כדי שהוא "יראה" את השרת שרשמתם.

> **הערה - Tool מול Resource:** שרת ה-Filesystem הרשמי חושף אך ורק **Tools** (כמו `read_text_file`, `write_file`, `list_directory`) - אין לו כלל יכולת Resources. זה ממחיש בדיוק את ההבדל שדיברנו עליו בתרגיל 1: Tool היא פעולה שהמודל *בוחר להפעיל* בעצמו (למשל "תקרא לי את הקובץ הזה"), בעוד ש-Resource הוא תוכן שה-Client יכול לצרף לשיחה בלי שהמודל "מבקש" אותו. לא כל שרת MCP חושף את שני הסוגים - וזה תקין לגמרי.

### משימות חקירה:
1.  שאלו את Claude Code: "אילו כלים (tools) חשופים לך דרך שרת ה-filesystem-exercise?" ודאו שהוא עונה עם שמות כלים אמיתיים (כמו `read_text_file`, `list_directory`, `write_file`) בלי לקרוא אף קובץ.
2.  שאלו את קלוד: "מהי מדיניות החברה לגבי מילואים?". ודאו שהוא באמת קורא את `miluim_policy.md` (למשל דרך הכלי `read_text_file`) כדי לענות, ולא עונה מהזיכרון שלו.
3.  בתיקיית ה-`tools`, צרו קובץ פייתון ריק בשם `calculate_nis_bonus.py`. פתחו session חדש של Claude Code ושאלו שוב אילו כלים חשופים לו. מה אתם רואים? האם הכלי ניתן להפעלה? הסבירו מדוע.
    - **רמז:** רשימת ה-Tools של שרת נתון קבועה בקוד המקור של השרת עצמו. שם התיקייה `tools` הוא רק מוסכמה שקבענו לעצמנו לצורך הסדר - לשרת אין שום מודעות לתיקייה הזו או לתוכן שבתוכה. כדי שקובץ Python יהפוך לכלי MCP אמיתי, צריך לכתוב אותו במפורש עם SDK (כמו FastMCP, שנלמד כבר בתרגיל 3 הבא) ולסמן פונקציה בו עם `@mcp.tool()`.

## תרגיל 3: בניית שרת FastMCP בסיסי (יחיד - 30 דקות)
עכשיו ניצור שרת MCP אמיתי עם כלי פונקציונלי באמצעות ספריית `FastMCP`. ניצור כלי רלוונטי לשוק הישראלי: בדיקת תקינות של מספר ח.פ (חברה פרטית) / ע.מ (עוסק מורשה).

### הנחיות:
1.  הקימו סביבה וירטואלית והתקינו את הספריות הדרושות:
    ```bash
    pip install "fastmcp[server]" uvicorn
    ```
2.  צרו קובץ פייתון חדש, לדוגמה `israeli_tools_server.py`.
3.  העתיקו את קוד ההתחלה הבא לקובץ שלכם.

### קוד התחלה:
```python
from fastmcp import FastMCP

mcp = FastMCP(name="שרת כלים ישראליים")


@mcp.tool()
def validate_israeli_business_id(business_id: str) -> dict:
    """
    Validates an Israeli business ID (H.P. or O.M.).
    It checks if the ID has 9 digits and if the check digit is correct.
    :param business_id: The 9-digit Israeli business ID string.
    :return: A dictionary with 'valid' (boolean) and a 'message'.
    """
    # --- השלימו את הלוגיקה כאן ---
    # 1. ודאו שהקלט הוא מחרוזת של 9 ספרות. אם לא, החזירו הודעת שגיאה.
    # 2. המירו את המחרוזת לספרות.
    # 3. יישמו את אלגוריתם "ספרת ביקורת" (חפשו בגוגל "אלגוריתם ספרת ביקורת תעודת זהות").
    #    האלגוריתם זהה עבור ח.פ.
    # 4. החזירו מילון עם התוצאה. למשל: {'valid': True, 'message': 'Business ID is valid.'}
    pass  # מחקו שורה זו


if __name__ == "__main__":
    mcp.run()
```

### משימות:
1.  השלימו את הלוגיקה של הפונקציה `validate_israeli_business_id`.
2.  חברו את השרת ל-Claude Code, באותה שיטה כמו בתרגיל 2:
    ```bash
    claude mcp add israeli-tools -- python israeli_tools_server.py
    ```
    (אם אתם משתמשים בסביבה וירטואלית שאינה מופעלת כרגע בטרמינל, כתבו את הנתיב המלא ל-`python` שבתוך תיקיית הסביבה הוירטואלית במקום `python`.) ודאו עם `claude mcp list` שהחיבור מסומן כ-`✔ Connected`, ופתחו session חדש (`claude`).
3.  בדקו את פעולת הכלי עם קלוד. נסו לשאול:
    *   "האם מספר הח.פ. 515545531 הוא תקין?" (אמור להיות תקין)
    *   "בדוק בבקשה את העוסק מורשה 123456789" (אמור להיות לא תקין)
    *   "512345678, תקין?"

### רמז:
אלגוריתם ספרת ביקורת: הכפילו כל ספרה (למעט ספרת הביקורת) במשקל שלה (1,2,1,2...). סכמו את התוצאות (אם תוצאת הכפל דו-ספרתית, סכמו את שתי הספרות). הסכום הכולל צריך להתחלק ב-10 ללא שארית.

## תרגיל 4: הרחבת שרת ה-MCP (יחיד/זוגות - 25 דקות)
נרחיב את השרת שבנינו בתרגיל 3 עם יכולת נוספת. בחרו **אחת** משתי המשימות הבאות.

### הנחיות:
הוסיפו את הקוד החדש לקובץ `israeli_tools_server.py` מהתרגיל הקודם.

### משימה א': הוספת כלי חדש
הוסיפו כלי חדש בשם `get_interest_rate_boi` שמחזיר את ריבית בנק ישראל העדכנית. מכיוון שאין לנו גישה קלה ל-API בזמן אמת, נחזיר ערך קבוע, אך נדאג שה-docstring יהיה ברור למודל.

```python
@mcp.tool()
def get_interest_rate_boi() -> dict:
    """
    Gets the current official interest rate from the Bank of Israel.
    :return: A dictionary with the rate and the last update date.
    """
    # In a real scenario, this would make an API call.
    # For this exercise, we return a mocked, hard-coded value.
    return {
        "rate_percent": 4.5,
        "last_update": "2026-05-10",
        "source": "Bank of Israel (Mock Data)"
    }
```

**בדיקה:** הריצו מחדש את `claude mcp list` (או פתחו session חדש אם השרת כבר היה מחובר) ושאלו את קלוד: "מהי ריבית בנק ישראל כרגע?".

### משימה ב': הוספת Resource
הוסיפו לשרת `Resource` המכיל מידע טקסטואלי על כללי הרגולציה לפתיחת עסק בישראל.

```python
REGULATIONS_INFO = """
# תקציר רגולציה לפתיחת עסק בישראל

1.  **רישום ברשויות:** יש להירשם במע"מ, מס הכנסה וביטוח לאומי.
2.  **צורת התאגדות:** ניתן לבחור בין עוסק פטור, עוסק מורשה או חברה בע"מ.
3.  **רישיון עסק:** עסקים מסוימים (כמו מסעדות) דורשים רישיון עסק מהרשות המקומית.
"""

@mcp.resource("resource://israeli-business-regulations")
def israeli_business_regulations() -> str:
    """Provides a summary of regulations for opening a new business in Israel."""
    return REGULATIONS_INFO
```

> **הערה:** בניגוד לשרת ה-Filesystem בתרגיל 2, כאן `@mcp.resource(...)` **חייב** לקבל URI כפרמטר ראשון (למשל `"resource://israeli-business-regulations"`) - זו דרישת חובה של הספרייה, לא רק שם תיאורי.

**בדיקה:** הריצו מחדש את `claude mcp list` (או פתחו session חדש אם השרת כבר היה מחובר) ושאלו את קלוד: "מה אני צריך לדעת כדי לפתוח עסק בישראל?".

## תרגיל 5: משימת בית - שרת MCP לצורך עסקי ישראלי (בית - 60 דקות)
בתרגיל זה תתכננו ותבנו מאפס שרת MCP שלם עבור תרחיש עסקי.

### התרחיש:
אתם מפתחים בצוות ה-AI של חברת **Wix**. המשימה שלכם היא לבנות שרת MCP עבור ה-AI Assistant הפנימי, שמסייע לאנשי תמיכה טכנית לפתור בעיות של לקוחות במהירות. השרת יספק כלים לביצוע פעולות נפוצות על אתרי לקוחות.

### דרישות:
1.  **תכנון (10 דקות):** לפני כתיבת הקוד, ענו על השאלה הבאה בקובץ טקסט נפרד: מדוע במקרה זה עדיף לבנות שרת MCP עם כלים מוגדרים היטב, במקום לתת למודל גישה ישירה ל-API הפנימי של Wix המכיל מאות endpoints? (חשבו על ביטחון, פשטות, שליטה, ו"עומס קוגניטיבי" על המודל).

2.  **מימוש (50 דקות):**
    *   צרו קובץ פייתון חדש `wix_support_server.py`.
    *   בנו שרת `FastMCP` המממש **לפחות שלושה** כלים מהרשימה הבאה (השתמשו באותו תבנית קוד כמו בתרגיל 3: `mcp = FastMCP(name=...)`, `@mcp.tool()`, וסיום הקובץ ב-`mcp.run()`).
    *   **חשוב:** הכלים צריכים להחזיר מידע מדומה (mock data). אינכם צריכים להתחבר למערכות אמיתיות.
    *   **רשימת כלים לבחירה:**
        *   `get_site_details(site_id: str)`: מקבל מזהה אתר ומחזיר פרטים כמו שם האתר, תאריך יצירה, והאם הוא מחובר לדומיין פרימיום.
        *   `check_domain_status(domain_name: str)`: מקבל שם דומיין ומחזיר אם הוא פנוי, תפוס על ידי לקוח Wix, או תפוס חיצונית.
        *   `list_installed_apps(site_id: str)`: מחזיר רשימה של אפליקציות (למשל, Wix Stores, Wix Bookings) המותקנות באתר מסוים.
        *   `publish_site(site_id: str)`: "מפרסם" אתר ומחזיר הודעת הצלחה.
        *   `add_user_to_role(site_id: str, user_email: str, role: str)`: מוסיף משתמש כ"אדמין" או "עורך" לאתר ומחזיר אישור.

### הנחיות הגשה:
הגישו שני קבצים:
1.  `wix_support_server.py` - קוד השרת המלא.
2.  `design_choice.txt` - התשובה לשאלת התכנון.
