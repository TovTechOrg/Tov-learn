# דוגי-סטייל אילוף מתקדם — Landing Page

## עסק
- **שם:** דוגי-סטייל אילוף מתקדם
- **מיקום:** אזור השרון — הרצליה, רעננה, כפר סבא
- **קהל יעד:** בעלי גורים ובעלי כלבים עם בעיות התנהגות
- **מטרת CRO:** איסוף לידים לשיחת ייעוץ חינם

## מבנה הדף (index.html)
| קטע | תוכן |
|-----|------|
| Nav | לוגו + טלפון + כפתור CTA |
| Hero | כותרת + תיאור + סטטיסטיקות + ויזואל כלב (canvas) |
| שירותים | אילוף גורים · תיקון התנהגות · ליווי מתמשך |
| תהליך | 3 שלבים ממוספרים: ייעוץ → תוכנית → תוצאות |
| אודות המאלף | עידן כהן — CPDT-KA, 12+ שנות ניסיון |
| עדויות | 3 ביקורות — הרצליה, רעננה, כפר סבא |
| טופס לידים | שם, טלפון, עיר, תיאור הבעיה |
| Footer | פרטי קשר |

## עיצוב
- **שפה:** עברית (RTL מלא)
- **פלטה:** ירוק יער `#0E4A2D` + נייבי `#1B4476` + מנטה `#CBE8D4`
- **גופן:** System font stack — `-apple-system, BlinkMacSystemFont, Segoe UI`
- **ויזואל הגיבור:** כלב גיאומטרי מונפש (Canvas API) — סגנון שרטוט הנדסי
- **אין תלויות חיצוניות** — הכל inline (CSS + JS)

## כללי פיתוח
- אל תוסיף CDN חיצוני (fonts, icons, scripts) — דף עצמאי לחלוטין
- שמור על RTL בכל האלמנטים
- הטופס: validation בסיסי, feedback ויזואלי לאחר submit
- נגישות: `focus-visible`, `aria-label`, `prefers-reduced-motion`
