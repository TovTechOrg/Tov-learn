# מנעולן אקספרס 24/7 — Emergency Landing Page

## עסק
- **שם:** מנעולן אקספרס 24/7
- **מיקום:** גוש דן
- **פרופיל לקוח:** לחוץ, עומד מחוץ לדלת, גולש מסמארטפון בלחץ
- **מטרה:** המרה מהירה ביותר — חיוג מיידי בלחיצה אחת

## עיקרון העיצוב
> **Mobile-only.** כל החלטת עיצוב מיועדת למסך 375–430px.  
> דסקטופ מקבל מרכוז פשוט — לא יותר.

## Above-the-fold (מה שנראה ללא גלילה)
1. שם העסק — קטן, בראש
2. כותרת דחופה — 2 שורות מקסימום
3. תג אמבר: ⚡ הגעה עד 20 דקות
4. כפתור CTA אדום ענק (22px, 22px padding) עם `animation: pulse`
5. Social proof: ✓ מעל 1,000 לקוחות בגוש דן

## רצועת Bottom-sticky
כפתור חיוג מוצמד לתחתית — גלוי תמיד גם בזמן גלילה.  
`position: fixed; bottom: 0` עם `safe-area-inset-bottom` ל-iPhone notch.

## ערכת עיצוב
| משתנה | ערך | שימוש |
|-------|-----|--------|
| `--bg` | `#0A0A0A` | רקע |
| `--red` | `#D9251D` | כפתור CTA |
| `--amber` | `#F59E0B` | תג "20 דקות" |
| `--green` | `#22C55E` | social proof |
| `--text-muted` | `rgba(255,255,255,0.55)` | טקסט משני |

## כללי פיתוח
- **אפס תלויות חיצוניות** — נטען offline, מיידי
- Click-to-call: `<a href="tel:XXXXXXXXXX">`
- אנימציה: `@keyframes` CSS בלבד (pulse על הכפתור)
- `maximum-scale=1.0` — מונע zoom אוטומטי בשדות
- `safe-area-inset-bottom` — תמיכה ב-iPhone עם notch
