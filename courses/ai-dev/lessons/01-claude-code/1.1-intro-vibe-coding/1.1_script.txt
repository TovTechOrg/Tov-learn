נתחיל עם Claude Code, הכלי שנקדיש לו שלושה שיעורים שלמים בהמשך המודול.

Claude Code הוא CLI, כלומר ממשק שורת פקודה, שרץ בטרמינל. Anthropic פיתחו אותו על גבי מודל Claude Opus ארבע נקודה שש, הכי חזק שיש. חלון ההקשר הוא מיליון טוקן, מה שאומר שהוא יכול לקרוא codebase שלם, תיעוד, ועוד, הכל יחד.

מה שהוא יכול לעשות: לבצע git commits, לכתוב קבצים, להריץ בדיקות, לתאם בין מספר סוכנים במקביל דרך Agent Teams. יש לו Voice Mode שבו מדברים אליו ישירות. יש את הפקודה loop שמריצה משימות בלולאה. אוטומציה ממש מלאה.

מבחינת ביצועים, בבנצ'מרק SWE-bench שבודק פתרון באגים אמיתיים מ-GitHub, Claude Code מגיע לאחוזים גבוהים מאוד, בראש הרשימה העולמית.

המחיר: Claude Pro עולה עשרים דולר לחודש. Claude Max יש בגרסות של מאה ומאתיים דולר. מפתח ממוצע מוציא בערך שישה דולר ביום.

מתי זה הבחירה? כשאתה מפתח מקצועי שרוצה להאיץ את העבודה. כשהפרויקט מורכב, כשיש codebase קיים, כשרוצים שליטה מלאה על כל פרט.

Ampcode מתאים במיוחד כשעובדים בצוות ורוצים פיצ'רים שיתופיים, או כשתקציב Claude Max גבוה מדי.

חיסרון אחד שנמצא בבדיקות: Gemini CLI צורך יותר טוקנים לאותה משימה. בבדיקה שהשוותה אותה עבודה, הוא השתמש בכמעט פי שניים טוקנים מ-Claude Code. כלומר עולה יותר להפעיל.

Codex CLI של OpenAI מבוסס על מודל GPT-5.3-Codex. הוא מהיר ואמין, ומתאים במיוחד לאינטגרציה עם מערכות OpenAI קיימות. יש תמיכה ב-MCP ועובד טוב עם CI/CD pipelines.

מתי לבחור Gemini? כשאתה כבר ב-Google ecosystem, כשרוצה חיפוש web בזמן אמת. מתי לבחור Codex? כשאתה כבר משתמש ב-OpenAI ורוצה אחידות, וכשהמשימות קצרות ומהירות.

המספרים של Lovable הם אחד הסיפורים המפתיעים ביותר של 2025 עד 2026. שמונה מיליון משתמשים נכון לפברואר אלפיים ועשרים ושש. עשרים וחמישה מיליון פרויקטים שנוצרו. ארבע מאות מיליון דולר הכנסה שנתית. מאה מיליון דולר הגיעו בשמונה חודשים בלבד. גיוס של שלוש מאות ושלושים מיליון דולר בדצמבר אלפיים ועשרים וחמש בשווי של שש נקודה שש מיליארד דולר. ובין המשקיעים, NVIDIA ו-Alphabet.

הנתון המרתק הוא האבולוציה בין הגרסאות. Agent ראשון הצליח לעבוד שתי דקות לבד. Agent שניים, עשרים דקות. Agent שלישי, מאתיים דקות. זה גידול פי מאה בתוך שנה וחצי.

מה הוא בונה? Web apps, אפליקציות מובייל עם backend, משחקים תלת ממדיים, מערכות נתונים, ואינטגרציות לשירותים כמו Slack ו-Telegram.

ב-2025, Replit יצר חמישה מיליון אפליקציות, ומתוכן רבע מיליון נפרסו לפרודקשן אמיתי.

Replit Agent מתאים כשרוצים אוטונומיה מקסימלית, כשיש משימות ארוכות שדורשות הרצה תיקון והרצה שוב, וכשרוצים Cloud IDE בלי לנהל סביבה מקומית.

אז מה למדנו היום?

Vibe Coding היא לא סתם כלי חדש, אלא שינוי פרדיגמה. מ"איך לכתוב קוד" ל"מה אני רוצה לבנות". אנדרז' קרפת'י טבע את המונח בפברואר אלפיים ועשרים וחמש, והעולם לא חזר אחורה מאז.

השוק הוא שנים עשר מיליארד דולר וגדל. שמונים וארבעה אחוז ממפתחים שם. חמישים ואחד אחוז מהקוד ב-GitHub כבר נכתב עם עזרת AI.

ראינו שישה כלים: ארבעה Terminal CLIs למפתחים, שני Web Builders לכולם, וכלי ענן אוטונומי. כל אחד מצוין בסיטואציה שלו. הבחירה הנכונה תלויה בסיטואציה ובצרכים הספציפיים שלך.

בשיעור הבא ניקח את Claude Code ונתחיל לעבוד איתו ממש. התקנה, הגדרה, ושבע רמות השליטה שיהפכו אתכם לאדוני ה-Vibe Coding.

תודה שהייתם איתי, ונתראה בשיעור הבא.
