# תרגילים - שיעור 1.1: מבוא ל-Vibe Coding

## מידע כללי
- **שיעור:** 1.1 - מבוא ל-Vibe Coding
- **סוג השיעור:** עיוני (2 שעות)
- **הערה:** שיעור עיוני – התרגילים ממוקדים בהבנה, ניתוח והתנסות ראשונית

---

## תרגיל 1: הגדרה בשפה שלכם (בכיתה – 5 דקות)

### הנחיות:
כתבו **בשלושה משפטים בלבד** – בלי לצטט את המצגת:
1. מה זה Vibe Coding?
2. מה ההבדל הגדול ביותר בינו לבין תכנות קלאסי?
3. למה לדעתכם הביטוי "שכחו שהקוד קיים" (forget that the code even exists) מסוכן?

### תיאור:
לאחר כתיבה – שתפו עם עמית/ה ותראו אם הגדרתם אותו דבר.

---

## תרגיל 2: בחירת הכלי הנכון (בכיתה – 10 דקות)

### הנחיות:
עבור כל תרחיש, כתבו **איזה כלי תבחרו ולמה** (משפט אחד):

### תרחישים:
1. **דני**, מפתח Backend עם 5 שנות ניסיון ב-Python, רוצה לבנות API פנימי לעסק קטן — לבד, בלי צוות.
2. **Data Scientist** שרוצה להוסיף UI פשוט ל-model שכבר כתב — אין לה ניסיון בפרונטאנד.
3. **סטארטאפ בן 4 אנשים** צריך MVP תוך שבוע. שני מהם מפתחים Full-Stack, שניים — Product.
4. **מפתח** שרוצה להוסיף feature קטן לקוד קיים בריפו מסובך שהוא לא כתב.
5. **צוות DevOps** שרוצה לכתוב Terraform + GitHub Actions לפרויקט חדש — אין זמן לכתוב הכל ידנית.

### הגשה:
שמרו את תשובותיכם – נשווה בין תשובות הכיתה ונדון בהבדלים.

---

## תרגיל 3: מה משתנה למפתח? (בכיתה – 7 דקות)

### הנחיות:
קראו את הנתונים הבאים וענו על השאלות:

**נתונים:**
- 84% ממפתחים בעולם משתמשים בכלי AI
- 51% מהקוד ב-GitHub נכתב עם עזרת AI
- Claude Code כותב קוד מ-E2E ומ-Deploy — לא רק משלים שורות

### שאלות:
1. אם 51% מהקוד כבר נכתב על ידי AI – מה לדעתכם המיומנות הכי חשובה למפתח ב-2026?
2. מה ההבדל בין "להשתמש ב-AI לכתיבת קוד" לבין "לבנות מוצר עם AI"?
3. תחשבו על הפרויקט האחרון שבניתם — כמה זמן היה אפשר לחסוך? מה עדיין היה דורש מגעכם?

---

## תרגיל 4: ניסיון ראשון עם Claude Code (שיעורי בית – 30 דקות)

### הנחיות:
1. ודאו ש-Claude Code מותקן (`claude --version`)
2. צרו תיקיה חדשה ריקה והריצו `claude` בתוכה
3. בנו את אחת מהאפשרויות הבאות **ב-3 פרומפטים בלבד**:
   - CLI tool ב-Python שמקבל קובץ CSV ומדפיס סיכום סטטיסטי (min, max, mean לכל עמודה נומרית)
   - REST API פשוט עם FastAPI — endpoint אחד שמקבל טקסט ומחזיר מילים ייחודיות ממוינות
   - סקריפט שסורק תיקיה ומייצר `report.md` עם מבנה הקבצים וגודל כל קובץ

### מה לתעד:
- את 3 הפרומפטים שכתבתם (מדויק)
- צילום מסך של הפלט הסופי
- **3 דברים שהפתיעו אתכם** (חיובי או שלילי)
- **משהו שרציתם לשנות אך לא הצלחתם בפרומפט**

### הגשה:
שתפו בקבוצת הקורס לפני השיעור הבא.

---

## תרגיל 5: השוואת גישות (שיעורי בית – 20 דקות)

### הנחיות:
בצעו **אותה משימה** בשתי גישות ותשוו:

**המשימה:**
כתבו פונקציה Python שמקבלת רשימת דיקשנריז ומחזירה אותם ממוינים לפי מפתח שנתון.

**גישה א' — Chat (ChatGPT / Claude.ai):**
כתבו את הבקשה ב-chat, קבלו קוד, העתיקו לקובץ .py והריצו.

**גישה ב' — Claude Code:**
פתחו תיקיה חדשה, הריצו `claude`, בקשו את אותה פונקציה — ותנו לו גם לכתוב test.

### מה להשוות:
| קריטריון | Chat | Claude Code |
|----------|------|-------------|
| זמן עד לקוד עובד | | |
| האם הריץ tests? | | |
| כמה קל לשנות | | |
| מה נשאר לי לעשות ידנית? | | |

### שאלת חשיבה:
באיזה סוג משימה Claude Code יתן לכם יותר ערך מ-Chat? מתי Chat מספיק?

---

## תרגיל 6: מחקר – הכלי שהכי מעניין אתכם (שיעורי בית – 15 דקות)

### הנחיות:
בחרו **כלי אחד** מהרשימה שהכי עניין אתכם בשיעור: Claude Code / Gemini CLI / Codex CLI / Ampcode / Cursor / Windsurf.

חפשו אותו באינטרנט (חפשו את שם הכלי + "review 2026") ומצאו:

### שאלות לחקור:
1. מה המחיר המדויק היום?
2. מה היכולת הכי ייחודית שלו שלא ציינו בשיעור?
3. מה הביקורת הכי נפוצה עליו ב-Reddit / Twitter?
4. איזה מפתח / סוג פרויקט הכי מרוויח ממנו?

### הגשה:
פסקה אחת של 4-6 משפטים שמסכמת את הממצאים שלכם.

## תרגיל 7: משימת בית – תוכנית פעולה אישית

### הנחיות:
כתבו **תוכנית פעולה אישית** בגוף ראשון:

1. **פרויקט שרוצה לבנות:** תארו בקצרה פרויקט אחד שהייתם רוצים לבנות עם Vibe Coding.
2. **הכלי שתבחרו:** איזה כלי תשתמשו בו ולמה?
3. **המחסום הכי גדול שלכם:** מה לדעתכם יהיה הדבר הכי קשה? (טכני? זמן? ידע?)
4. **מה תלמדו בשלב הבא:** מה חסר לכם כדי להתחיל?

### פורמט:
4-8 משפטים, בשפה ישירה ואישית.

**הגישו עד השיעור הבא.**
