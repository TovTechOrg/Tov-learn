## תרגיל 3: חישוב עלויות API (עבודה אישית - 10 דקות)

### תרחיש:
אתם בונים **צ'אטבוט לוואטסאפ** לחנות אונליין. הבוט עונה על שאלות לקוחות.

נתונים:
- ממוצע 50 שיחות ביום
- כל שיחה: ~500 tokens Input (שאלת הלקוח + system prompt) + ~300 tokens Output (תשובת הבוט)
- 30 ימי עבודה בחודש

### חשבו:
**א.** כמה tokens סה"כ בחודש?
- Input: 50 × 500 × 30 = _____ tokens
- Output: 50 × 300 × 30 = _____ tokens

**ב.** חשבו את העלות החודשית עבור כל מודל:

| מודל | מחיר Input (למיליון tokens) | מחיר Output (למיליון tokens) | עלות חודשית |
|---|---|---|---|
| Claude Sonnet 4.6 | $3 | $15 | $ |
| GPT-5.4 Instant | $2.50 | $10 | $ |
| Gemini 3.1 Pro | $1.25 | $5 | $ |

**ג.** אם הלקוח משלם 500 ש"ח בחודש על הבוט – האם זה רווחי?

### תשובות:
**א.** Input: 750,000 tokens / Output: 450,000 tokens

**ב.**
- Claude Sonnet: (0.75 × $3) + (0.45 × $15) = $2.25 + $6.75 = **$9 לחודש**
- GPT-5.4 Instant: (0.75 × $2.50) + (0.45 × $10) = $1.875 + $4.50 = **$6.375 לחודש**
- Gemini 3.1 Pro: (0.75 × $1.25) + (0.45 × $5) = $0.9375 + $2.25 = **$3.19 לחודש**

**ג.** כן! 500 ש"ח = ~$135. עלות AI מקסימלית: $9. רווח גולמי: $126 = ~465 ש"ח. + עלויות אירוח, Make/n8n, WhatsApp API, ועבודה שלכם.

## תרגיל 4: בחירת Stack טכנולוגי (עבודה קבוצתית - 15 דקות)

### תרחיש:
לקוח פנה אליכם עם הבקשה הבאה:

**"אני מנהל סוכנות נדל"ן עם 20 סוכנים. כל יום אנחנו מקבלים עשרות פניות מלקוחות – בוואטסאפ, במייל, ובטלפון. אני צריך מערכת שתענה ללקוחות אוטומטית, תסווג את הפנייה, ותעביר לסוכן הנכון. גם אני רוצה דוח שבועי על כל הפניות."**

### משימות:

**א.** בחרו את ה-Stack הטכנולוגי:

| רכיב | הכלי שבחרתם | למה? |
|---|---|---|
| מודל AI לבוט | | |
| פלטפורמת אוטומציה | | |
| ממשק וואטסאפ | | |
| CRM / בסיס נתונים | | |
| כלי לדוחות | | |

**ב.** כמה לדעתכם תעלה המערכת הזו בחודש? (תשלומי AI + כלים)

**ג.** כמה הייתם גובים מהלקוח עבור הקמה? ותחזוקה חודשית?

**ד.** מה הסיכון הכי גדול בפרויקט הזה?

### תשובה לדוגמה:

| רכיב | כלי | סיבה |
|---|---|---|
| מודל AI | Claude Sonnet 4.6 | טוב בסיווג טקסט, מחיר סביר |
| אוטומציה | Make.com | ויזואלי, קל לתחזוקה, AI Agent מובנה |
| וואטסאפ | WhatsApp Business API via Make | חיבור רשמי, אמין |
| CRM | Google Sheets / Airtable | פשוט, הלקוח מכיר |
| דוחות | Make + Google Sheets + AI summary | אוטומטי כל שבוע |

עלות חודשית: Make Pro ~$60, Claude API ~$30, WhatsApp API ~$20 = **~$110/חודש**
הקמה: 5,000-8,000 ש"ח. תחזוקה: 500-1,000 ש"ח/חודש.

## תרגיל 5: משימת בית – ניסוי אישי

### הנחיות:
בחרו **משימה אמיתית** מהחיים/מהעבודה שלכם ושלחו אותה לשלושת הכלים (ChatGPT, Claude, Gemini).

דוגמאות למשימות:
- כתבו מייל מקצועי ללקוח
- תסכמו מסמך ארוך
- תבקשו רעיונות לפוסט ברשתות חברתיות
- תבקשו ניתוח של טבלת נתונים

### מה להגיש:
1. מה המשימה שבחרתם?
2. הפרומפט ששלחתם (אותו אחד לכולם)
3. התשובות מכל שלושת הכלים (צילומי מסך או העתקה)
4. מי נתן את התשובה הכי טובה ולמה?
5. מה הפתיע אתכם?

**הגשה:** עמוד אחד. להביא לשיעור הבא.
