- **הערה:** התרגילים בנויים בדרגת קושי עולה. תרגילים 2-6 מתבצעים בתוך Claude Code בתיקיית ניסיון (sandbox) ולא בתיקיות האישיות שלכם. אין צורך בידע בתכנות.

לפניכם חמישה הרגלים שלכם מהצ'אט. לכל אחד כתבו מה עושים במקומו ב-Claude Code, במשפט אחד. אפשר לענות על דף או במסמך.

| # | הרגל בצ'אט | מה עושים ב-Claude Code? |
|---|---|---|
| 1 | מעלים קובץ אקסל ומבקשים סיכום | |
| 2 | מקבלים קוד, מעתיקים ומדביקים בעורך | |

| 4 | השיחה התארכה והצ'אט מתבלבל | |

## תרגיל 2: מפגש ראשון בטוח בתיקיית ניסיון (20 דקות)
### הנחיות:
1. צרו תיקייה חדשה וריקה בשם `sandbox` (למשל בתיקיית Documents, בתוך תיקייה נפרדת, לא על שולחן העבודה).
2. פתחו את Claude Code בתוך התיקייה (מומלץ דרך VS Code עם התוסף של Claude Code: פתחו את התיקייה ב-VS Code ואז את חלון Claude).
3. בקשו, בסדר הזה, וקראו בקפידה כל בקשת אישור לפני שאתם מאשרים:
   - `תסביר לי מה יש בתיקייה הזאת` (קריאה בלבד, אמור להגיד שהיא ריקה)
   - `צור קובץ בשם kniyot.txt עם רשימת קניות של חמישה פריטים לשבת`
   - `הוסף לקובץ עוד שני פריטים ומיין את הרשימה לפי הא"ב`
   - `מחק את הקובץ`  (שימו לב איזו בקשת אישור מופיעה, ואשרו רק אם הבנתם אותה)
4. בכל שלב רשמו: מה הוא ביקש לעשות? מה אישרתם? האם התוצאה תאמה את הציפייה?

### שאלות:
1. מה ההבדל בין בקשה שלא דרשה אישור לבקשה שדרשה?
2. מה קרה לקובץ ב-Windows Explorer / Finder בזמן שעבדתם?

## תרגיל 3: הצבעה על קובץ במקום העלאה (15 דקות)
### הנחיות:
בתוך `sandbox` צרו (או בקשו מ-Claude ליצור) קובץ בשם `orders.csv` עם התוכן הבא, שמדמה הזמנות של חנות פרחים קטנה:

```csv
date,customer,item,qty,price
2026-01-03,דנה,זר ורדים,1,120
2026-01-03,יוסי,עציץ סחלב,2,85
2026-01-04,מיכל,זר שמש,1,95
2026-01-05,דנה,עציץ סחלב,1,85
2026-01-05,אבי,זר ורדים,3,120
```

עכשיו, בלי להדביק את התוכן בצ'אט, כתבו ל-Claude Code:
1. `תקרא את orders.csv ותגיד לי כמה הכנסה הייתה בכל יום`
2. `מי הלקוח שהזמין הכי הרבה?`
3. `תכתוב לי קובץ summary.txt עם שלוש תובנות לבעלת החנות, בעברית פשוטה`

### שאלות:
1. מה היה הניסוח שלכם לבקשה השלישית, והאם התוצאה היתה מדויקת? אם לא, איך תיקנתם?
2. בדקו חישוב אחד ידנית. האם Claude צדק?

## תרגיל 4: כתיבת CLAUDE.md קצר (15 דקות)
### הנחיות:
ב-Claude Code, ה-CLAUDE.md הוא המקבילה של הוראות הפרויקט בצ'אט. כתבו קובץ `CLAUDE.md` בתיקיית `sandbox` (אפשר לכתוב בעצמכם, או לבקש מ-Claude לנסח טיוטה ואז לערוך אותה) לפי השלד:

```markdown
# פרויקט: ניתוח הזמנות לחנות פרחים

## על מה הפרויקט
(משפט או שניים)

## כללי עבודה
- (שפת התשובות)
- (אורך התשובות)
- (מה לא נוגעים בו: למשל orders.csv מקורי)

## מונחים
- "זר" = ...
```

אחרי שכתבתם, נקו את השיחה עם הפקודה `/clear`, והתחילו שיחה חדשה עם: `מה אתה יודע על הפרויקט הזה?`

### שאלות:
1. האם Claude ידע על הפרויקט בלי שהסברתם מחדש? מה הוא ציטט מהקובץ?
2. הוסיפו כלל שהתעלמתם ממנו בדעתכם, למשל "תמיד תסיים בשורת סיכום". האם הוא קוים?

## תרגיל 5: נקודת שמירה וביטול דרך גיט (20 דקות)
### הנחיות:
1. בקשו מ-Claude: `תאתחל כאן repository של git ותעשה commit ראשון עם הקבצים הקיימים`. קראו את הפקודות שהוא מבקש להריץ לפני האישור.
2. בקשו: `תשנה את summary.txt כך שיהיה באורך משפט אחד בלבד`.
3. הסתכלו על התוצאה, ואז בקשו: `תראה לי מה השתנה מאז ה-commit האחרון`.
4. החליטו שהשינוי לא טוב, ובקשו: `תחזיר את summary.txt למצב של ה-commit האחרון`.
5. ודאו שהקובץ חזר לקדמותו.

### שאלות:
1. מה הערך של ה-commit שעשיתם לפני השינוי?
2. מה היה קורה אם לא היתה נקודת שמירה והקובץ לא היה מתאים לכם?
3. מתי הייתם עושים commit חדש בפרויקט האמיתי שלכם?

## תרגיל 6: חשיבה בצ'אט, בנייה ב-Claude Code (אתגר - 25 דקות)
### הנחיות:
בחרו אחד מפרויקטי הגמר (מערכת תמיכה בוואטסאפ, שירות מסמכים חכמים, סוכן טלגרם יומי, או מנוע סקירת קוד) או רעיון משלכם לעסק קטן בישראל, למשל קליניקה, מספרה או חנות אונליין.

**שלב א, בצ'אט (Claude Desktop או הדפדפן):** נהלו שיחה קצרה עם Claude: מי המשתמש, מה שלוש המשימות העיקריות של המערכת, מה היא לא עושה. בקשו בסוף: `סכם את זה כמסמך plan.md קצר, עם כותרות ורשימות`.

**שלב ב, שמירה:** העתיקו את הסיכום לקובץ `plan.md` בתיקיית `sandbox`.

**שלב ג, ב-Claude Code:** כתבו: `תקרא את plan.md ותציע תוכנית בנייה בשלבים קטנים, בלי לשנות שום קובץ`. (אפשר גם להפעיל מצב תכנון עם Shift ו-Tab.) קראו את התוכנית ואז בקשו ממנו לבצע רק את שלב 1.

### שאלות:
1. איזה חלק בעבודה היה נוח יותר בצ'אט ואיזה ב-Claude Code?
2. מה הקובץ plan.md נתן לכם שלא היה לכם אם רק העתקתם הודעות?
3. כתבו כלל אצבע אישי: מתי אני פותח צ'אט ומתי Claude Code?

### בונוס: עברית במסוף
אם ראיתם עברית הפוכה או מבולבלת בזמן העבודה, רשמו מה ניסיתם (VS Code עם התוסף, תוסף RTL, או מצב english only של המורה הדיגיטלי) ומה עבד לכם.

**הגישו את תשובות התרגילים 1, 4 ו-6 (ואת הקובץ CLAUDE.md שכתבתם) עד השיעור הבא.**

## הנחיות למרצה

**תרגיל 1, תשובות טובות:**
1. מצביעים על הקובץ בנתיב או בשם ומבקשים ממנו לקרוא (`תקרא את הקובץ ...`), ללא העלאה.
2. הוא כותב את הקובץ בעצמו ומבקש אישור, אין העתקה.
3. כותבים את ההוראות בקובץ CLAUDE.md בתיקיית הפרויקט.
4. `/clear` להתחלה נקייה, או `/compact` לכיווץ השיחה לסיכום. מומלץ לשמור סיכום בקובץ לפני כן.
5. מחזירים את השינוי דרך גיט, ולכן חשוב לשמור commit לפני עבודה.
בונוס: ב-Claude Code התשובות משנות קבצים אמיתיים ויכולות להריץ פקודות, לכן חשובה קריאת בקשות האישור ונקודת שמירה.

**תרגיל 2:** המטרה היא להפיג פחד, לא ללמוד פקודות. ודאו שהמשתתפים קוראים את בקשת האישור ושמים לב שקריאה בלבד לרוב לא מצריכה אישור בניגוד לכתיבה ומחיקה. בשאלה 2, הקובץ מופיע בתיקייה בזמן אמת: זו נקודת האור, התוצאה היא קובץ אמיתי.

**תרגיל 3, תוצאות צפויות:** 2026-01-03: 120 + 170 = 290. 2026-01-04: 95. 2026-01-05: 85 + 360 = 445. הלקוח עם הכי הרבה פריטים: אבי (3 יחידות), לפי כמות יחידות; לפי סכום הוצאה: אבי 360. אם Claude נתן תשובה שונה, זו הזדמנות לדון בצורך לבדוק חישובים.

**תרגיל 4:** תשובה טובה כוללת משפט תיאור ברור, 2-3 כללים קונקרטיים (למשל "לענות בעברית פשוטה, עד 5 שורות" ו"לא לערוך את orders.csv המקורי"). אחרי `/clear` Claude אמור להכיר את תוכן הקובץ. אם לא, בדקו שהפעלתם את Claude בתוך תיקיית sandbox ושם הקובץ בדיוק CLAUDE.md.

**תרגיל 5:** שלוש הפעולות הן commit ראשוני, שינוי, וחזרה לקובץ השמור. ודאו שהמשתתפים מבינים שבלי commit אין למה לחזור. קבלו גם מי שמבקש גיט ידנית אם הוא מכיר אותו.

**תרגיל 6, תשובה טובה:** plan.md עם משתמש, 3 משימות ומה לא נכלל; תוכנית בנייה בשלבים קטנים; ביצוע שלב אחד בלבד. כלל אצבע לדוגמה: צ'אט לחשיבה, השוואה ונוסח לקוח; Claude Code כשצריך לקרוא, לכתוב או להריץ משהו בתוך הפרויקט.
