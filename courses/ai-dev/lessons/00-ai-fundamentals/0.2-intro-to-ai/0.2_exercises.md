## תרגיל 3: ניתוח מקרה – "מה AI יכול לעשות לעסק שלי?" (עבודה קבוצתית - 15 דקות)

### תרחיש:
**"שירות פלוס"** היא חברת שירות לקוחות קטנה עם 15 עובדים. בעל העסק מתלונן על הבעיות הבאות:
- "אני מפספס פניות של לקוחות כי אני לא מספיק לענות לכולם בוואטסאפ"
- "כל פעם לשלוח תזכורת גבייה ללקוחות זה מתיש"
- "אנחנו שולחים את אותו מייל הסבר לכל לקוח חדש – ידנית"
- "אין לי מושג אילו קמפיינים מביאים לי לקוחות ואילו בזבוז כסף"
- "אני מבזבז שעתיים ביום על מילוי דוחות ב-Excel"

### משימות:

**א.** לכל בעיה, הציעו פתרון מבוסס AI (כלי ספציפי או סוג כלי):

| # | הבעיה | פתרון AI מוצע | כלי/טכנולוגיה |
|---|---|---|---|
| 1 | פיספוס פניות בוואטסאפ | | |
| 2 | תזכורות גבייה ידניות | | |
| 3 | מייל הסבר ידני | | |
| 4 | חוסר מידע על קמפיינים | | |
| 5 | מילוי דוחות ידני | | |

**ב.** אילו מהפתרונות הכי קלים להטמעה? דרגו מ-1 (קל) עד 5 (מורכב).

**ג.** במה הייתם מתחילים ולמה?

**ד.** מה הסיכון הכי גדול בכל הטמעה?

### תשובות לדוגמה:

| 2 | אוטומציית גבייה – שליחת תזכורות אוטומטיות לפי תאריכי יעד | Make + Google Sheets + WhatsApp | 2 |

## תרגיל 4: זיהוי הזיות (עבודה אישית - 10 דקות)

### הנחיות:
להלן 5 טענות שנוצרו על ידי AI. קבעו לגבי כל אחת: **אמת, שקר (הזיה), או לא ניתן לקבוע.**

| # | הטענה | אמת / שקר / לא ברור | למה? |
|---|---|---|---|
| 1 | "ג'ון מקארתי טבע את המונח 'בינה מלאכותית' ב-1956 בכנס בדרטמות'" | | |
| 2 | "ChatGPT הגיע ל-100 מיליון משתמשים תוך שבועיים מרגע ההשקה" | | |
| 3 | "חברת NVIDIA נוסדה ב-1993 על ידי ג'נסן הואנג ושני שותפים" | | |
| 4 | "מודל השפה Claude נקרא על שם קלוד שאנון, אבי תורת המידע" | | |
| 5 | "ארכיטקטורת ה-Transformer הומצאה ב-Google Brain ב-2017" | | |

### תשובות:
1. **אמת** – ג'ון מקארתי אכן טבע את המונח בכנס דרטמות' ב-1956
2. **שקר (הזיה)** – ChatGPT הגיע ל-100 מיליון משתמשים תוך חודשיים (לא שבועיים)
3. **אמת** – NVIDIA נוסדה ב-1993 על ידי ג'נסן הואנג, כריס מלכובסקי וקרטיס פריים
4. **אמת** – Claude אכן נקרא על שם קלוד שאנון
5. **אמת** – המאמר "Attention Is All You Need" פורסם על ידי צוות של Google Brain ב-2017

**הלקח:** AI טועה לעיתים בפרטים קטנים (מספרים, תאריכים) אבל המבנה הכללי נשמע אמין. תמיד בדקו מספרים ועובדות.

## תרגיל 5: דיון – מה הייתם בונים? (דיון כיתתי - 10 דקות)

### הנחיות:
כל סטודנט בוחר **פרויקט אחד** שהיה רוצה לבנות עד סוף הקורס, ומציג אותו לכיתה ב-30 שניות:

1. **מה הבעיה** שהפרויקט פותר?
2. **למי זה מיועד** (לעסק שלכם? ללקוחות? לשוק?)
3. **אילו כלים** לדעתכם יידרשו?

**טיפ למרצה:** רשמו את הרעיונות על הלוח. חזרו אליהם במהלך הקורס ועזרו לסטודנטים לממש אותם.

דוגמאות נפוצות שיעלו:
- "בוט לוואטסאפ שעונה ללקוחות" → מודולים 1+2
- "אפליקציה לניהול עסק" → מודול 3
- "מערכת שיווק אוטומטית" → מודולים 1+6
- "סוכן AI שמנהל את המייל שלי" → מודולים 2+5

## תרגיל 6: משימת בית – סקירת כלי AI (מחקר עצמי)

### הנחיות:
בחרו **כלי AI אחד** מהרשימה הבאה (או כלי אחר שמעניין אתכם) ורשמו דוח קצר:

**כלים לבחירה:** ChatGPT, Claude, Gemini, Make.com, n8n, ManyChat, Midjourney, Kling, Claude Code

### שאלות למחקר:
1. מה הכלי עושה?
2. כמה עולה (חינמי/בתשלום)?
3. מה היתרון המרכזי שלו לעומת מתחרים?
4. תנו דוגמה ל-use case עסקי אחד
5. מה המגבלה הכי גדולה שלו?
6. האם ניסיתם אותו? מה הרושם?

**הגשה:** חצי עמוד עד עמוד אחד. להביא לשיעור הבא.
