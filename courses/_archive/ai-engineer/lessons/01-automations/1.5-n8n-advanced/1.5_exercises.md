# תרגילים - שיעור 1.5: n8n מתקדם

## מידע כללי
- **שיעור:** 1.5 – n8n מתקדם
- **סוג השיעור:** מעשי (2 שעות)
- **הערה:** כל תרגיל דורש חשבון n8n פעיל (Cloud או Self-Hosted)

---

## תרגיל 1: מיפוי A2A לעסק קיים (15 דקות)

### הנחיות:
חשבו על עסק שאתם מכירים (שלכם, של לקוח, או דוגמה מהקורס). תארו כיצד תבנו עבורו מערכת Agent-to-Agent.

### שאלות:
1. מה ה-Orchestrator Agent עושה?
2. כמה Specialist Agents יש? מה תפקיד כל אחד?
3. אילו נתונים ה-Orchestrator מעביר לכל Specialist?
4. כיצד ה-Orchestrator יחליט לאיזה Specialist לפנות?

### דוגמה לדיון:
חברת נדל"ן: Orchestrator מקבל פנייה → Lead Qualification Agent בודק רצינות → Matching Agent מוצא נכסים מתאימים → Outreach Agent כותב מייל אישי.

---

## תרגיל 2: בניית Execute Sub-Workflow (25 דקות)

### הנחיות:
בנו שני Workflows ב-n8n שעובדים יחד:

**Sub-Workflow (הכין מראש):**
- Trigger: When called by another workflow
- Input: `customer_name` (שם לקוח) ו-`issue` (תיאור בעיה)
- עיבוד: AI Node (Claude/GPT) כותב טיוטת תשובה מקצועית
- Output: החזר את הטיוטה

**Main Workflow:**
- Trigger: Webhook
- הוסיפו AI Agent Node
- הוסיפו Tool מסוג "Execute Sub-Workflow" שמפנה ל-Sub-Workflow
- הורו ל-Agent: "כשמגיעה פנייה מלקוח, השתמש ב-Tool לכתיבת תשובה"

### בדיקה:
שלחו Webhook עם `{"customer_name": "ישראל ישראלי", "issue": "המוצר לא הגיע"}` ובדקו שה-Agent קורא ל-Sub-Workflow ומחזיר תשובה.

---

## תרגיל 3: Human-in-the-Loop עם Wait Node (30 דקות)

### הנחיות:
בנו Workflow של אישור הצעת מחיר:

1. **Webhook Trigger** — קולט: `client`, `service`, `budget`
2. **AI Node** — כותב הצעת מחיר קצרה בעברית
3. **Gmail/Slack Node** — שולח הצעה לכתובת/ערוץ שלכם עם שני לינקים:
   - `https://your-n8n/webhook/approve?id=XXX`
   - `https://your-n8n/webhook/reject?id=XXX`
4. **Wait Node** — ממתין עד שעה אחת
5. **IF Node** — אם אושר: שלח מייל ללקוח. אם נדחה/Timeout: שמור ב-Google Sheets לטיפול ידני.

### שאלות לאחר הבנייה:
- מה קורה אם אף אחד לא אישר תוך שעה?
- איך תשנו את הזמן ל-24 שעות?
- מה היתרון על פני HITL ברמת Tool?

## תרגיל 4: ניתוח Self-Hosting (20 דקות)

### הנחיות:
לקוח פוטנציאלי — מרפאת שיניים עם 300 מטופלים — מבקש אוטומציה לתזכורות פגישות. הוא אומר: "אני לא רוצה שנתוני המטופלים שלי יהיו אצל אף חברת ענן."

### שאלות:
1. האם תמליצו על n8n Cloud או Self-Hosted? נמקו.
2. אילו עלויות חודשיות תציגו בהצעת המחיר? (פרטו: VPS, תחזוקה, SSL)
3. מה ה-Setup הטכני המינימלי הנדרש? (רשמו את הצעדים)
4. מה הסיכונים שצריך להציג בפני הלקוח?
5. כתבו פסקת הצעה קצרה (5-6 שורות) שתוכלו לשלוח ללקוח.

## תרגיל 5: Docker Setup (30 דקות)

### הנחיות:
אם יש לכם גישה ל-VPS (Digital Ocean, AWS, Hetzner, או מכונה וירטואלית), בצעו את ההתקנה הבאה:

**שלב א'** — התקינו Docker על השרת:
```
curl -fsSL https://get.docker.com | sh
```

**שלב ב'** — הריצו n8n עם Docker:
```
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

**שלב ג'** — גשו ל-`http://YOUR_IP:5678` וצרו Admin Account.

**שלב ד'** — ייבאו Workflow שבניתם ב-n8n Cloud (Export JSON → Import).

### אם אין VPS:
תעדו את הצעדים שהייתם מבצעים + ציינו איזה VPS Provider הייתם בוחרים ולמה.

## תרגיל 6 (משימת בית): מערכת A2A + HITL מלאה

### הנחיות:
בנו מערכת אוטומטית מלאה שמשלבת A2A ו-HITL לעסק לבחירתכם.

**דרישות מינימום:**
- לפחות שני Agents (Orchestrator + Specialist אחד)
- נקודת HITL אחת לפחות לפעולה קריטית
- Error Handler שמתעד כשלים
- תיעוד של הארכיטקטורה (דיאגרמה פשוטה)

**רעיונות לתרחישים:**
- מערכת גיוס: סינון קו"ח → HITL לאישור ראיון → שליחת הזמנה
- מערכת תמיכה: סיווג פנייה → HITL לתלונות חמורות → מעקב
- מערכת מכירות: ניקוד ליד → HITL להצעת מחיר → CRM

**הגישו עד השיעור הבא:** Screenshot/Export של ה-Workflow + פסקת הסבר קצרה.
