# תרגילים - שיעור 1.4: n8n בסיס – התקנה, בניית Workflows, AI Nodes

## מידע כללי
- **שיעור:** 1.4 - n8n בסיס
- **סוג השיעור:** מעשי (4 שעות)
- **הערה:** כל התרגילים מתבצעים ב-n8n Cloud או Self-Hosted

---

## תרגיל 1: Hello World — ה-Workflow הראשון (10 דקות)

### הנחיות:
1. צרו Workflow חדש ב-n8n
2. השאירו את ה-Manual Trigger הקיים
3. הוסיפו Node "Set" וצרו את השדות הבאים:
   - `greeting` = "שלום מ-n8n!"
   - `my_name` = השם שלכם
   - `timestamp` = Expression: `{{ $now.toFormat('dd/MM/yyyy HH:mm') }}`
4. הריצו את ה-Workflow ובדקו את הפלט

### שאלות:
1. מה מופיע בפלט של ה-Set Node?
2. מה קורה אם משנים את ה-Expression ל-`{{ $now.plus(1, 'day').toFormat('dd/MM/yyyy') }}`?
3. במה שונה Manual Trigger מ-Schedule Trigger?

---

## תרגיל 2: Google Sheets — קריאה וכתיבה (20 דקות)

### הנחיות:
1. צרו Google Sheet עם העמודות: שם, אימייל, סטטוס, תאריך
2. הוסיפו 5 שורות עם נתוני דוגמה (סטטוס: new/sent/done)
3. בנו Workflow:
   - **Trigger:** Manual (לבדיקה)
   - **Node 1:** Google Sheets — Read Rows (קריאת כל השורות)
   - **Node 2:** IF — סנן רק שורות עם status = "new"
   - **Node 3:** Set — הוסף שדה `processed_at` עם התאריך הנוכחי
   - **Node 4:** Google Sheets — Update Row — עדכנו status ל-"processed"
4. הריצו ובדקו שהשורות התעדכנו ב-Google Sheets

### שאלות:
1. כמה שורות עברו דרך ה-IF Node? כמה נסננו?
2. מה קורה אם מריצים שוב? (רמז: אין יותר שורות "new")
3. איך הייתם הופכים את זה לאוטומטי עם Schedule Trigger?

---

## תרגיל 3: Webhook — קבלת מידע מבחוץ (20 דקות)

### הנחיות:
1. צרו Workflow חדש עם Webhook Trigger (POST)
2. לחצו "Listen for Test Event"
3. שלחו POST request ל-Test URL (דרך הדפדפן, Postman, או curl):

```json
{
  "name": "ישראל ישראלי",
  "email": "israel@test.com",
  "service": "אוטומציה לעסק",
  "budget": "5000"
}
```

4. הוסיפו Nodes לעיבוד:
   - **Set Node:** הוסיפו שדה `received_at` וחשבו מחיר+מע"מ: `{{ $json.budget * 1.17 }}`
   - **Google Sheets:** שמרו את הליד בגיליון
5. הריצו ובדקו שהנתונים נשמרו

### שאלות:
1. מה ההבדל בין Test URL ל-Production URL?
2. מתי צריך לעבור ל-Production URL?
3. איך דף נחיתה ישלח Webhook ל-n8n?

## תרגיל 4: Expressions מתקדמים (15 דקות)

### הנחיות:
כתבו את ה-Expressions הבאים ובדקו אותם ב-Set Node:

| # | מטרה | Expression |
|---|-------|-----------|
| 1 | שם מלא משני שדות | `{{ $json.firstName + ' ' + $json.lastName }}` |
| 2 | מחיר עם מע"מ | `{{ ($json.price * 1.17).toFixed(2) }}` |
| 3 | תאריך מחר | `{{ $now.plus(1, 'day').toFormat('dd/MM/yyyy') }}` |
| 4 | תנאי (אם מחיר > 1000) | `{{ $json.price > 1000 ? 'VIP' : 'Regular' }}` |
| 5 | אימייל באותיות קטנות | `{{ $json.email.toLowerCase() }}` |

### אתגר:
כתבו Expression שמקבל שם מלא באנגלית ומחזיר רק את האות הראשונה של כל שם (ראשי תיבות).
למשל: "John David Smith" → "JDS"

## תרגיל 5: סיווג אימיילים עם AI (25 דקות)

### הנחיות:
1. צרו Workflow עם Manual Trigger
2. הוסיפו Set Node עם דוגמאות אימיילים (העבירו אחד בכל הרצה):

| # | נושא | תוכן |
|---|------|-------|
| 1 | "המוצר התקלקל" | "קניתי את המוצר לפני שבוע והוא כבר לא עובד. מבקש החזר כספי מלא." |
| 2 | "שאלה על משלוחים" | "האם אתם שולחים לאילת? כמה זמן לוקח המשלוח?" |
| 3 | "בקשת הצעת מחיר" | "אנחנו חברה של 50 עובדים ומעוניינים ברישיון Enterprise. אפשר הצעת מחיר?" |
| 4 | "הזדמנות עסקית!!!" | "הרוויח $10,000 ביום!!! לחץ כאן עכשיו!!!" |
| 5 | "תודה על השירות" | "רציתי להגיד תודה. השירות היה מצוין והמוצר הגיע מהר." |

3. הוסיפו AI Agent Node:
   - Chat Model: OpenAI GPT-4o (או Claude)
   - System Message:
   ```
   אתה מסווג אימיילים. סווג כל אימייל לקטגוריה אחת:
   - complaint (תלונה)
   - question (שאלה)
   - quote_request (בקשת הצעת מחיר)
   - spam (ספאם)
   - positive_feedback (משוב חיובי)

   החזר JSON: {"category": "...", "confidence": 0-100, "summary": "סיכום בשורה אחת"}
   ```

4. הוסיפו Switch Node שמנתב לפי הקטגוריה

### שאלות:
1. באיזו רמת ביטחון (confidence) ה-AI סיווג כל אימייל?
2. האם היו טעויות? מה יגרום ל-AI לטעות?
3. מה היתרון של AI על פני כללים ידניים (מילות מפתח)?

## תרגיל 6: AI Agent עם כלים (25 דקות)

### הנחיות:
1. צרו Workflow עם n8n Chat Trigger
2. הוסיפו AI Agent Node עם:
   - **Chat Model:** OpenAI GPT-4o
   - **System Message:** "אתה עוזר חכם לעסק ישראלי. ענה בעברית. השתמש בכלים שלך כדי לענות."
   - **Memory:** Window Buffer Memory (5 הודעות)
3. הוסיפו כלים:
   - **Calculator** — לחישובים
   - **Google Sheets Tool** — חברו ל-Sheet עם מחירון מוצרים (שם מוצר, מחיר, מלאי)

4. בדקו עם השאלות:
   - "כמה עולה מוצר X?" (Agent ישתמש ב-Sheets)
   - "אם אקנה 5 יחידות של מוצר X, כמה זה עם מע"מ?" (Agent ישתמש ב-Calculator + Sheets)
   - "אילו מוצרים יש במלאי?" (Agent ישתמש ב-Sheets)
   - "מה שאלתי קודם?" (Agent ישתמש ב-Memory)

### שאלות:
1. באיזה כלי ה-Agent השתמש לכל שאלה?
2. האם ה-Agent זכר את השיחה הקודמת?
3. מה קורה אם שואלים שאלה שאין לה תשובה ב-Sheets?

## תרגיל 7: פרויקט עצמאי — בחרו ובנו! (30 דקות)

### הנחיות:
בחרו **אחד** מהתרחישים ובנו אותו מאפס:

### תרחיש א': ניטור מחירים
- Schedule Trigger (כל שעה)
- HTTP Request לAPI חיצוני (למשל: exchangerate-api.com לשער דולר)
- IF — אם השער מעל/מתחת לערך מסוים
- שליחת התראה (Email / Telegram / Slack)
- שמירה ב-Google Sheets

### תרחיש ב': מערכת לידים חכמה
- Webhook (POST) — קבלת ליד
- AI Agent — סיווג הליד (חם/קר/ספאם)
- Switch — ניתוב לפי סיווג
- Google Sheets — שמירה
- Email — התראה על ליד חם

### תרחיש ג': סיכום RSS עם AI
- Schedule Trigger (כל 6 שעות)
- HTTP Request ל-RSS Feed (למשל Ynet, TechCrunch)
- AI Agent — סיכום הכתבה ל-3 משפטים בעברית
- Google Sheets — שמירת הסיכומים
- Email/Slack — שליחת סיכום יומי

### פורמט הגשה:
- צילום מסך של ה-Workflow המוכן
- הסבר קצר: מה עושה כל Node
- הדגמה חיה (הרצה ותוצאות)

## תרגיל 8: משימת בית — Workflow לעסק אמיתי

### הנחיות:
1. חשבו על עסק (שלכם, של מישהו שאתם מכירים, או דמיוני)
2. זהו תהליך ידני שאפשר לאוטמט
3. בנו Workflow ב-n8n שמאוטמט אותו
4. הגישו:
   - תיאור העסק והתהליך (3-5 שורות)
   - צילום מסך של ה-Workflow
   - הסבר Node-by-Node
   - מה החיסכון הצפוי? (זמן / כסף / טעויות)

### דוגמאות לרעיונות:
- מעקב אחרי הזמנות ושליחת עדכונים ללקוחות
- איסוף לידים מטופס ושליחת מייל אוטומטי
- ניטור מתחרים ושליחת דוח יומי
- ניהול משימות צוות עם התראות

**הגישו עד השיעור הבא.**
